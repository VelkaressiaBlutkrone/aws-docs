계정 삭제

구름사다리 계정과 동기된 학습 기록을 삭제하는 방법입니다.

앱을 설치하지 않아도 됩니다. 같은 기능이 웹 앱에 있어 브라우저에서 바로 삭제할 수 있고, 이메일로 요청할 수도 있습니다.

방법 1 — 웹이나 앱에서 직접 삭제

  1. 웹 앱 https://velkaressiablutkrone.github.io/aws-docs/ 를 열거나 Android 앱을 엽니다.
  2. 오른쪽 위 메뉴(넓은 화면에서는 설정)에서 기기 간 동기를 누릅니다.
  3. 로그인되어 있지 않다면 Google로 동기 켜기로 삭제할 계정에 로그인합니다.
  4. 계정 삭제를 누르고 확인합니다.
  5. 보안을 위해 Google 계정으로 한 번 더 확인하면 삭제가 끝납니다.

방법 2 — 이메일로 요청

info@leva.ai.kr로 제목을 「구름사다리 계정 삭제 요청」으로, 본문에 로그인에 쓴 Google 계정 이메일을 적어 보내 주세요. 본인 확인 뒤 지체 없이 삭제하고 결과를 회신합니다.

삭제되는 것과 남는 것

삭제됩니다

  • Firebase 계정 — Google 계정 이메일, 사용자 ID, 로그인으로 받은 기본 프로필
  • 클라우드에 동기된 학습 기록 전부 — 응시 기록, 열람 기록, 학습 계획과 진행 상태, 동기 정보
  • 방법 1로 삭제한 경우 그 기기(또는 브라우저)에 저장된 학습 기록

남는 것

  • 삭제를 실행하지 않은 다른 기기·브라우저에 저장된 학습 기록 — 그 기기에서 「모든 학습 기록 초기화」를 누르거나 앱을 삭제하면 지워집니다.
  • 서비스 제공자 측 기록 — Google은 Firebase Authentication이 로그인 IP 주소를 몇 주 동안 보관하고, 계정 삭제 뒤 그 밖의 인증 정보를 운영 시스템과 백업에서 180일 안에 지운다고 밝힙니다.
  • Google 계정 자체 — 이 앱의 계정만 삭제되며 Google 계정은 그대로입니다.
