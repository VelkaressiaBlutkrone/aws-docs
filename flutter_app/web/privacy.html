시행일 2026-11-23 · 운영자 leva

요약 — 로그인하지 않고 쓰면 학습 기록은 이 기기에만 저장되고 운영자에게 전송되지 않습니다. 「기기 간 동기」를 켜서 Google 계정으로 로그인한 경우에만 계정 정보와 학습 기록이 Google Firebase에 저장됩니다. 광고·분석·충돌 보고 도구는 쓰지 않습니다. 앱 안에서 언제든 계정과 기록을 삭제할 수 있습니다(계정 삭제 안내).

구름사다리는 AWS 자격증을 한국어로 공부하기 위한 비공식 학습 도구이며, Amazon Web Services, Inc. 및 Amazon.com, Inc.와 제휴하거나 그 승인·후원을 받지 않았습니다. 「AWS」 및 관련 명칭은 해당 소유자의 상표입니다.

2. 수집하는 정보

로그인하지 않고 쓸 때

응시 기록, 오답·표시한 문항, 학습 문서 열람 기록, 학습 계획과 진행 상태, 화면 설정(다크 모드 등)은 사용하는 기기에만 저장됩니다(웹은 브라우저 저장소, Android는 앱 전용 저장 공간). 로그인하지 않으면 이 기록은 운영자나 다른 곳으로 전송되지 않습니다.

「기기 간 동기」를 켜서 Google 계정으로 로그인했을 때

여러 기기에서 같은 기록을 이어 보도록 다음 정보를 Google Firebase에 저장합니다. 동기 기능은 선택이며 켜지 않아도 모든 학습 기능을 쓸 수 있습니다.

항목내용
계정 정보Google 계정 이메일, Firebase가 만든 사용자 ID, Google 로그인 응답에 담길 수 있는 기본 프로필(이름·프로필 사진 주소). 앱 화면과 동기에는 이메일과 사용자 ID만 씁니다.
로그인 보안 정보Firebase Authentication이 가입·로그인 과정의 보안과 악용 방지를 위해 처리하는 IP 주소와 기기·브라우저 정보(운영체제 버전, 기기 모델, SDK 버전 등)

동기하는 학습 기록

로그인한 계정 아래(users/사용자 ID)에 다음 종류의 기록이 저장됩니다.

  • 응시 기록 — 시험·퀴즈 종류, 점수, 제시·오답·표시한 문항 번호, 소요 시간, 응시 시각
  • 열람 기록 — 자격증별로 연 학습 문서와 그 시각
  • 학습 계획 — 사용자가 만든 자격증별 학습 일정
  • 계획 진행 — 학습 계획 항목의 진행 상태
  • 동기 정보 — 초기화·삭제 시각처럼 여러 기기의 기록을 맞추는 데 쓰는 정보
  • 이전 버전 기록 — 예전 앱의 계획 체크 기록. 지금은 쓰지 않으며 남아 있으면 동기 과정에서 정리됩니다

보내 주신 의견

앱 안에서 의견을 보내면 아래 내용이 저장됩니다. 여러 기기에서 맞추는 동기 대상은 아니며, 운영자가 읽습니다.

  • 보낸 의견 — 의견의 유형과 본문, 보낸 시각, 앱 버전과 플랫폼(웹·Android). 문항 오류 신고라면 그 문항의 식별자와 화면에 보여 드린 보기

웹 앱을 열 때

웹 앱은 화면을 그리는 엔진과 로그인 SDK, 일부 글자의 글꼴을 Google의 콘텐츠 전송망(gstatic.com)에서 받고, 페이지 자체는 GitHub Pages에서 받습니다. 이 과정에서 해당 서버가 접속 IP 주소와 브라우저 정보를 처리합니다.

강의 음성을 재생할 때

웹 앱과 Android 앱은 사용자가 강의 음성을 재생하면 음성 파일을 Cloudflare에서 받습니다. 이 과정에서 Cloudflare가 접속 IP 주소와 브라우저 또는 앱의 요청 정보를 처리합니다. 앱은 사용자의 음성을 녹음하거나 수집하지 않습니다.

수집하지 않는 것

광고 식별자, 위치, 연락처, 사진·파일, 결제 정보는 수집하지 않습니다. 광고·분석·충돌 보고 도구를 쓰지 않으며 광고·추적 목적의 쿠키를 쓰지 않습니다.

3. 이용 목적

  • 로그인과 계정 관리
  • 여러 기기 사이의 학습 기록 동기화
  • 로그인 과정의 보안 유지와 악용 방지

수집한 정보를 광고, 판매, 다른 서비스와의 결합, 자동화된 프로필 분석에 쓰지 않습니다.

4. 제3자 제공과 처리 위탁

개인정보를 판매하거나 제3자에게 제공하지 않습니다. 서비스 운영을 위해 다음 사업자가 운영자를 대신해 정보를 처리합니다.

사업자처리 내용
Google LLC — Google Firebase로그인(Firebase Authentication)과 동기 기록 저장(Cloud Firestore)
Google LLC — gstatic.com웹 앱의 화면 엔진·로그인 SDK·글꼴 전송(웹만)
Cloudflare, Inc. — R2 (aws-audio.leva.ai.kr)강의 음성 파일 전송(웹·Android)
GitHub, Inc. — GitHub Pages웹 앱과 이 문서의 호스팅(웹만)

학습 문서 안의 AWS 공식 문서 링크는 사용자가 눌렀을 때 기기의 브라우저로 열리며, 그 이후는 해당 사이트의 방침이 적용됩니다.

5. 국외 이전

  • 동기 학습 기록은 Cloud Firestore의 서울 리전(asia-northeast3)에 저장됩니다.
  • 로그인 정보는 Firebase Authentication이 처리하며, Google은 이 서비스가 미국 데이터센터에서만 운영된다고 밝힙니다. 로그인 시점에 네트워크로 이전됩니다.
  • 웹 전송망(gstatic.com · GitHub Pages)과 강의 음성 전송(Cloudflare)은 각 사업자의 전 세계 인프라에서 처리됩니다.

6. 안전성 확보 조치

  • 모든 전송은 HTTPS(TLS)로 암호화됩니다.
  • 데이터베이스 보안 규칙이 로그인한 본인의 기록만 읽고 쓰게 하며, 다른 사용자나 로그인하지 않은 접근은 거부합니다.
  • 비밀번호를 받거나 저장하지 않습니다(Google 계정으로만 로그인).

7. 보존 기간과 삭제

  • 동기 학습 기록·계정 정보: 사용자가 계정을 삭제하거나 삭제를 요청할 때까지 보존합니다. 로그아웃만 하면 클라우드의 기록은 남습니다.
  • 계정 삭제: 앱의 「기기 간 동기 → 계정 삭제」를 누르면 클라우드의 동기 기록, Firebase 계정, 그 기기의 학습 기록을 지웁니다. 자세한 단계와 앱 없이 요청하는 방법은 계정 삭제 안내에 있습니다.
  • 서비스 제공자 측 보존: Google은 Firebase Authentication이 로그인 IP 주소를 몇 주 동안 보관하고, 계정이 삭제된 뒤 그 밖의 인증 정보를 운영 시스템과 백업에서 180일 안에 지운다고 밝힙니다. Cloud Firestore에는 시점 복구용 백업을 켜 두지 않았습니다.
  • 기기의 기록: 앱의 「모든 학습 기록 초기화」, 앱 삭제, 브라우저 사이트 데이터 삭제로 지울 수 있습니다.
