# 기본 AI 개념과 용어 (용어·계층·추론 유형·데이터 유형·학습 유형)

> **커버하는 공식 Task** — AIF-C01 · 도메인 1 「AI 및 ML의 기초」(20%) · **작업 1.1 기본 AI 개념과 용어 설명** (`aif-t1-1`)
> 이 문서는 위 한 작업에 1:1로 매핑되고 공식 목표 5개(1.1.1~1.1.5)를 모두 덮습니다. 이 시험의 모든 문항이 여기서 정의한 낱말로 쓰여 있으니, **용어를 가르는 질문 한 줄**을 갖는 것이 가장 빠른 투자입니다.

> ⚠️ **가이드 v1.1에서 바뀐 것** — 목표 1.1.1의 용어 목록에 **생성형 AI(GenAI)와 에이전틱 AI**가 들어왔고, 1.1.2는 **"AI, ML, GenAI, 딥 러닝, 에이전틱 AI 간의" 차이**를 묻게 바뀌었습니다. 1.1.3의 추론 유형도 배치·실시간 둘에서 **비동기·서버리스까지 네 가지**로 늘었습니다. 2026-04-30 이전 교재는 이 셋을 빠뜨립니다.

## 🧭 시험 형식 (14편 중 여기서 한 번만 정리합니다)

공식 가이드가 적는 사실입니다. 시험장에서 처음 보면 당황하는 부분이라 먼저 짚습니다.

| 항목 | 값 |
|---|---|
| 채점 문항 | **50개** |
| 채점되지 않는 문항 | **15개**(시험에서 식별되지 않습니다) |
| 시험 시간 | **90분** · 응시 화면 문항 **65개** |
| 합격 최소 점수 | **700**(변환 점수 100~1,000) |
| 채점 모델 | **보상 점수 모델** — 섹션마다 합격할 필요가 없고 전체 시험만 합격하면 됩니다 |

문항 유형은 **네 가지**이고 채점 규칙이 다릅니다.

- **선다형** — 정답 1개, 오답 3개
- **복수 응답형** — 5개 이상의 응답 중 정답 2개 이상. **정답을 모두 선택해야** 점수를 받습니다
- **순서 배열** — 3~5개 응답을 **올바른 순서로 배열**해야 점수를 받습니다
- **매칭형** — 3~7개 프롬프트와 응답의 **모든 쌍을 정확히 맞춰야** 점수를 받습니다

> ⚠️ **답하지 않은 문항은 오답으로 채점되고 추측에 따른 불이익은 없습니다.** 모르는 문항도 반드시 표시하고 넘어갑니다.
> 이 사이트의 연습 문항은 **선다형**으로 제공됩니다. 나머지 세 유형은 "모두 맞아야 득점"이라는 성질만 기억하면 되고, 묻는 지식은 같습니다.

## ✅ 학습 목표 체크리스트

- [ ] AI · ML · 딥 러닝 · GenAI · 에이전틱 AI를 **포함 관계와 하는 일**로 가른다
- [ ] 신경망 · 컴퓨터 비전 · NLP · 음성 인식이 각각 **무엇을 입력으로 받는지** 말할 수 있다
- [ ] 편향 · 공정성 · 적합성(과적합·과소적합)을 구분하고 왜 ML이 **확률적**인지 설명한다
- [ ] 추론 유형 네 가지를 **지연·페이로드·엔드포인트 유지 여부**로 고른다
- [ ] 레이블 데이터와 비레이블 데이터, 정형과 비정형, 테이블·시계열·이미지·텍스트를 구분한다
- [ ] 지도 · 비지도 · 강화 학습을 **무엇을 주고 무엇을 기대하는가**로 가른다
- [ ] LLM과 FM의 관계를 알고, FM이 **자기 지도 학습**으로 훈련된다는 것을 안다
- [ ] 시험 문항 유형 네 가지와 채점 규칙을 안다

## 🎯 왜 중요한가

도메인 1은 전체의 **20%**이고, 그중 1.1은 **낱말**입니다. 낱말을 잘못 알면 다른 네 도메인의 문항을 읽을 수 없습니다. 예를 들어 "이 워크로드에 적합한 추론 유형은?"이라는 문항은 서비스 지식이 아니라 **네 유형의 정의**만 알면 풀립니다.

이 작업의 문항은 모델을 만들게 하지 않습니다. 공식 가이드가 대상 응시자를 **"AI/ML 솔루션을 사용해야 하지만, 반드시 구축할 필요는 없다"**고 적고, 범위 밖 작업으로 **모델·알고리즘 개발, 특성 추출 구현, 하이퍼파라미터 튜닝, 파이프라인 구축, 수학·통계 분석**을 명시합니다. 그래서 공부 방향은 **"무엇을 고르고 왜"**이지 **"어떻게 만드는가"**가 아닙니다.

## ⚡ 시험 직전 요약

> 시험 직전에 이 열 줄만 다시 봅니다. 근거와 맥락은 아래 본문에 있습니다.

- **포함 관계**: AI ⊃ ML ⊃ 딥 러닝. 공식은 ML을 **"AI를 달성하는 하나의 방법"**으로, 딥 러닝을 **"인공 신경망을 쓰는 특수한 형태의 ML"**로 적습니다
- **GenAI와 과거 AI의 차이는 "생성"**입니다 — 과거 AI는 데이터 **분석**에 한정됐고 GenAI는 이미지·비디오·텍스트·오디오를 **새로 만듭니다**
- **에이전틱 AI의 차이는 "자율"**입니다 — 전통 AI는 **프롬프트와 단계별 안내**가 필요하지만 에이전틱 AI는 목표만 주면 **선제적으로** 복잡한 작업을 수행합니다
- **ML은 확률적입니다** — "이렇게 하면 저렇게 된다"가 아니라 **"X% 확률로 저렇게 된다"**
- **추론 네 유형**: 실시간(대화형·저지연) · 서버리스(인프라 관리 없음, **콜드 스타트 허용**) · 비동기(요청을 **큐에 넣고** 처리, **큰 페이로드**) · 배치 변환(**대규모 데이터셋**, 영구 엔드포인트 **불필요**)
- ⚠️ **배치 변환에서 입력 파일 1개에 인스턴스를 여러 개 띄우면 한 인스턴스만 일하고 나머지는 유휴**입니다. 병렬화는 파일을 나눠야 생깁니다
- **지도는 레이블 데이터**, **비지도는 비레이블 데이터**. 비지도는 패턴·이상 탐지·그룹화에 강하지만 **정밀한 예측은 못 합니다**
- **준지도**는 소량 레이블 + 대량 비레이블이고 중간에 **의사 레이블링(pseudo-labeling)**이 들어갑니다
- **강화 학습은 보상**으로 배웁니다. ⚠️ 보상을 설계하는 사람이 결과에 **개발자 편향**을 넣을 수 있습니다
- ⚠️ **FM은 비지도가 아니라 자기 지도(self-supervised)**입니다 — 공식은 FM이 **"입력 데이터에서 레이블을 만든다"**고 적습니다. LLM은 FM의 한 종류입니다

## 🔤 먼저 알아야 할 용어

| 용어 | 뜻 |
|---|---|
| **모델** | 입력과 출력 사이의 수학적 관계를 담은 결과물. 알고리즘이 데이터로 그 관계를 **찾아** 파라미터에 담습니다 |
| **알고리즘** | 그 관계를 찾는 **절차**. 모델과 알고리즘은 결과물과 방법으로 구분합니다 |
| **훈련(training)** | 데이터로 파라미터를 조정해 예측과 실제의 차이를 줄이는 단계 |
| **추론(inference)** | 훈련된 모델로 **예측을 얻는** 단계. 배포 형태가 네 가지입니다 |
| **편향(bias)** | 특정 집단·결과에 치우친 학습. 데이터나 설계에서 들어옵니다 |
| **공정성(fairness)** | 그 치우침이 **집단 간 결과 차이**로 나타나지 않는 성질 |
| **적합성(fit)** | 모델이 데이터를 **얼마나 맞게** 학습했는가. 지나치면 과적합, 모자라면 과소적합입니다 |
| **과적합(overfitting)** | 훈련 데이터에 너무 맞춰 **새 데이터에서 성능이 떨어지는** 상태 |
| **과소적합(underfitting)** | 패턴을 충분히 학습하지 못해 훈련 데이터에서도 못 맞히는 상태 |
| **토큰** | 모델이 텍스트를 다루는 최소 단위. 요금과 길이 제한의 단위이기도 합니다(도메인 2에서 다룹니다) |
| **파운데이션 모델(FM)** | 광범위한 일반 데이터로 사전 훈련돼 **여러 작업을 그대로 수행하는** 대규모 딥 러닝 신경망 |
| **대규모 언어 모델(LLM)** | 언어를 다루는 FM. **FM의 한 종류**입니다 |

## 📖 핵심 개념

### 1) 용어와 계층 — AI · ML · 딥 러닝 (목표 1.1.1) {#terms}

공식 정의를 그대로 옮기면 세 낱말의 관계가 선명합니다.

- **AI**는 **"기계가 인간과 유사한 문제 해결 작업을 수행하게 하는"** 기술입니다. 이미지 인식, 창작물 생성, 데이터 기반 예측이 모두 들어갑니다.
- **ML**은 **"명시적 지시 없이 데이터 분석 작업을 수행하는 AI의 한 유형"**입니다. 공식은 **"ML은 AI의 여러 분야 중 하나"**이며 **"AI를 달성하는 방법"**이라고 적습니다. 즉 **모든 ML은 AI지만 모든 AI 활동이 ML은 아닙니다.**
- **딥 러닝**은 **"인공 신경망을 사용해 인간의 뇌를 모방하는 특수한 형태의 ML"**입니다. 공식은 딥 러닝이 **"생성형 AI 발전의 토대를 놓았다"**고 적습니다.

ML이 하는 일은 **수정 가능한 수학 함수 하나**로 설명됩니다. 공식 문서의 예가 직관적입니다 — `(2,10)`·`(5,19)`·`(9,31)`을 주면 알고리즘이 `o = 3*i + 4`를 찾아내고, 입력 7에 대해 25를 예측합니다.

**신경망**은 **노드(인공 뉴런)**들이 함께 정보를 처리하는 구조입니다. 데이터가 **입력층 → 여러 "깊은" 은닉층 → 출력층**으로 흐르고, 은닉층이 많을수록 표준 ML보다 훨씬 복잡한 학습이 가능해집니다.

그 위에 올라가는 응용 기술은 **입력이 무엇인가**로 가릅니다.

| 기술 | 입력 | 하는 일 |
|---|---|---|
| **NLP** | 텍스트 | 의미를 해석·생성. 문서 요약, 챗봇, 감정 분석 |
| **컴퓨터 비전** | 이미지·비디오 | 정보와 인사이트 추출. 콘텐츠 검토, 얼굴 인식, 이미지 분류 |
| **음성 인식** | 음성 | 단어 식별·의미 탐지. 텍스트 변환, 음성 감정 표시 |

### 2) GenAI와 에이전틱 AI — 무엇이 달라졌는가 (목표 1.1.2) {#genai-agentic}

v1.1이 이 둘을 용어 목록과 비교 대상에 넣었습니다. 가르는 기준은 각각 **하나**입니다.

**GenAI를 가르는 기준은 「생성」**입니다. 공식은 GenAI를 **"간단한 텍스트 프롬프트로 이미지·비디오·텍스트·오디오 같은 새 콘텐츠와 결과물을 만드는 AI 시스템"**으로 정의하고, 결정적으로 **"데이터 분석에 한정됐던 과거 AI와 달리"**라고 적습니다. 즉 분류·예측만 하는 모델은 GenAI가 아닙니다.

**에이전틱 AI를 가르는 기준은 「자율」**입니다. 공식 정의는 **"사전 결정된 목표를 달성하기 위해 독립적으로 행동할 수 있는 자율 AI 시스템"**이고, 비교 문장이 셋을 한 줄로 세웁니다 — **전통 소프트웨어는 미리 정의된 규칙을 따르고, 전통 AI도 프롬프트와 단계별 안내가 필요하지만, 에이전틱 AI는 선제적이어서 지속적인 인간 감독 없이 복잡한 작업을 수행합니다.**

공식이 적는 에이전틱 AI의 특징은 **네 가지**입니다.

| 특징 | 뜻 |
|---|---|
| **선제적(proactive)** | 입력을 기다리지 않고 필요를 예상해 먼저 움직입니다 |
| **적응적(adaptable)** | 실시간 입력과 도메인 지식으로 행동을 조정합니다 |
| **협업적(collaborative)** | 사람·다른 에이전트와 공동 목표를 이해하고 조율합니다 |
| **전문화(specialized)** | 좁은 전문 영역의 **초전문화 에이전트 여럿**을 조합합니다 |

동작은 **인지(perceive) → 추론(reason) → 행동(act) → 학습(learn)** 네 단계이고, 다중 에이전트 구성은 **수평형(horizontal)**과 **수직형(vertical)**으로 나뉩니다. 세부는 도메인 2의 작업 2.1에서 다룹니다.

> ⚠️ **"에이전틱 AI"와 "에이전트 AI"는 공식 한국어 가이드 안에서 표기가 갈립니다.** 목표 1.1.1·1.1.2는 「에이전틱 AI」, 목표 2.1.6은 「에이전트 AI」로 적습니다. 같은 것을 가리키니 둘 다 알아 두면 됩니다.

### 3) 추론 유형 네 가지 (목표 1.1.3) {#inference-types}

v1.1에서 **비동기와 서버리스가 추가**된 자리입니다. SageMaker AI 공식 문서의 서술로 가릅니다.

| 유형 | 공식이 적는 선택 이유 | 가르는 질문 |
|---|---|---|
| **실시간(real-time)** | **대화형·저지연** 요구가 있는 워크로드 | 사용자가 응답을 기다리는가 |
| **서버리스(serverless)** | 기반 인프라를 **구성·관리하지 않고** 배포. **트래픽 사이에 유휴 구간**이 있고 **콜드 스타트를 감수할 수 있는** 워크로드 | 트래픽이 띄엄띄엄한가 |
| **비동기(asynchronous)** | 들어오는 요청을 **큐에 넣고 비동기로 처리**. **페이로드가 큰** 요청에 적합 | 요청이 크고 즉시 응답이 필요 없는가 |
| **배치 변환(batch transform)** | **대규모 데이터셋**에서 추론. **영구 엔드포인트가 필요 없을 때**. 전처리로 노이즈·편향 제거, **입력 레코드와 추론 결과를 연결** | 쌓아 둔 데이터를 한꺼번에 처리하는가 |

배치 변환의 동작에는 함정이 하나 있습니다. 배치 변환은 입력 S3 객체를 **키로 분할해 인스턴스에 매핑**합니다. 그래서 파일이 여러 개면 인스턴스들이 나눠 처리하지만, **입력 파일이 하나인데 인스턴스를 여럿 띄우면 한 인스턴스만 그 파일을 처리하고 나머지는 유휴 상태로 남습니다.** 병렬화를 원하면 파일을 나누거나 미니 배치로 분할해야 합니다.

### 4) 데이터 유형 (목표 1.1.4) {#data-types}

이 목표는 **데이터를 보고 쓸 수 있는 방법을 고르는** 연습입니다.

- **레이블 데이터 ↔ 비레이블 데이터** — 레이블링은 **입력 데이터를 그에 대응하는 출력 값으로 분류해 두는 것**입니다. 공식 예가 명확합니다: 수백만 장의 사과·바나나 이미지에 "사과"·"바나나" 태그를 달아 두면, 그 훈련 데이터로 새 과일 이미지의 이름을 맞힐 수 있습니다. ⚠️ 공식이 지적하는 한계는 **"수백만 개의 비레이블 데이터셋에 레이블을 다는 일 자체가 어렵다"**는 것입니다.
- **정형 ↔ 비정형** — 테이블처럼 행·열이 정해진 것과, 문서·이미지·오디오처럼 그렇지 않은 것.
- **테이블 형식 · 시계열 · 이미지 · 텍스트** — 같은 문제도 데이터 형태가 다르면 기법이 달라집니다. 시계열이면 시간 순서가 의미를 갖고, 이미지면 컴퓨터 비전, 텍스트면 NLP가 붙습니다.

### 5) 학습 유형 (목표 1.1.5) {#learning-types}

공식 가이드가 예로 드는 것은 **지도 · 비지도 · 강화**이고, 같은 공식 문서가 **준지도**와 **딥 러닝**까지 학습 스타일로 함께 싣습니다.

| 유형 | 무엇을 주는가 | 무엇을 기대하는가 | 공식이 적는 한계 |
|---|---|---|---|
| **지도** | **레이블 데이터**(입력과 출력 모두) | 한정된 결과 집합 예측, 범주 분류 | 레이블링 비용이 크다 |
| **비지도** | **비레이블 데이터** | 패턴 인식, 이상 탐지, 자동 그룹화 | ⚠️ **정밀한 예측을 주지 못하고** 특정 결과를 독립적으로 집어내지 못한다 |
| **준지도** | **소량 레이블 + 대량 비레이블** | 레이블 비용을 줄이면서 지도 수준에 접근 | — (중간에 **의사 레이블링**이 들어간다) |
| **강화** | **단계마다 보상 값** | 보상을 최대화하며 목표 도달 | ⚠️ 실제 환경이 자주·크게 변해 실효를 내기 어렵고, **보상을 설계하는 사람의 편향**이 결과에 들어간다 |

**비지도 학습의 쓸모를 외우는 방법**은 "정답을 모를 때"입니다. 공식 예 — 여러 뉴스 사이트의 기사를 스포츠·범죄 같은 공통 범주로 **묶거나**, 소매에서 "버터를 사면 빵도 살 가능성이 높다" 같은 **패턴을 찾는** 일입니다.

**FM은 이 표의 어디에 들어갈까요.** 공식은 FM이 **"광범위한 일반화되고 비레이블인 데이터로 훈련된다"**고 하면서, 동시에 **"FM은 자기 지도 학습(self-supervised learning)을 사용해 입력 데이터에서 레이블을 만든다"**고 적습니다. 그리고 이것이 **"지도 또는 비지도 학습을 쓰던 이전 ML 아키텍처와 LLM을 구분하는 특징"**이라고 못박습니다. 그래서 "FM은 비지도 학습으로 훈련된다"는 서술은 정확하지 않습니다.

### 6) ML은 왜 확률적인가 (목표 1.1.1의 「적합성」과 이어집니다) {#probabilistic}

공식 문서에 전용 절이 있습니다. 출력이 예측 가능하면 **결정론적**이라고 하고, 대부분의 소프트웨어는 "사용자가 이렇게 하면 저렇게 된다"로 동작합니다. 그런데 **ML 알고리즘은 관찰과 경험으로 배우므로 본질적으로 확률적**이어서, 문장이 **"사용자가 이렇게 하면 저렇게 될 확률이 X%다"**로 바뀝니다.

이것이 시험에서 쓰이는 방식은 두 가지입니다.

1. **"예측 대신 특정 결과가 반드시 필요한 상황"**에는 ML이 적절하지 않습니다(작업 1.2의 목표 1.2.2가 바로 이것을 묻습니다).
2. **적합성 문제**가 여기서 나옵니다 — 과적합은 훈련 데이터에 지나치게 맞춰 **새 데이터에서** 성능이 떨어지는 것이고, 과소적합은 패턴을 **덜** 학습한 것입니다.

## ✍️ 시험 포인트

- **포함 관계 문항**은 "모든 X는 Y인가"로 묻습니다 — 모든 ML은 AI지만 **그 역은 아닙니다.** 딥 러닝은 ML의 **부분집합**입니다.
- **GenAI 판별 문항**은 결과물을 봅니다 — **새 콘텐츠를 만들면** GenAI, **분류·예측만 하면** 전통 ML입니다.
- **에이전틱 AI 판별 문항**은 **감독의 양**을 봅니다 — 프롬프트마다 사람이 다음 단계를 지시하면 에이전틱이 아닙니다.
- **추론 유형 문항**은 세 축으로 갈립니다 — **사용자가 기다리는가**(실시간) · **페이로드가 큰가**(비동기) · **엔드포인트를 유지할 필요가 있는가**(배치 변환) · **트래픽이 띄엄띄엄한가**(서버리스).
- **학습 유형 문항**은 **데이터에 레이블이 있는지**만 먼저 보면 절반이 갈립니다. 레이블이 일부만 있으면 **준지도**, 보상이 등장하면 **강화**입니다.
- **용어 함정**은 편향·공정성·적합성 세 낱말을 섞습니다 — 편향은 **치우침**, 공정성은 그 치우침이 **집단 간 결과 차이로 나타나지 않음**, 적합성은 **데이터에 얼마나 맞췄는가**입니다.

## ⚠️ 흔한 함정 {#pitfalls}

- ❌ **"FM은 비레이블 데이터로 훈련되니 비지도 학습이다"** → 공식은 **자기 지도 학습**이라고 적고, 그것이 이전 아키텍처와의 **구분점**이라고 명시합니다.
- ❌ **"딥 러닝은 ML과 다른 기술이다"** → 딥 러닝은 **ML의 특수한 형태**입니다. 신경망을 쓰는 것이 구분점입니다.
- ❌ **"배치 변환에서 인스턴스를 늘리면 항상 빨라진다"** → **입력 파일이 하나면** 한 인스턴스만 일하고 나머지는 유휴입니다.
- ❌ **"비동기 추론과 배치 변환은 같은 것이다"** → 비동기는 **요청을 큐에 넣는 엔드포인트**이고(큰 페이로드), 배치 변환은 **영구 엔드포인트 없이** 대규모 데이터셋을 처리하는 **작업**입니다.
- ❌ **"서버리스 추론은 모든 경우에 낫다"** → 공식은 **콜드 스타트를 감수할 수 있는** 워크로드로 범위를 적습니다. 저지연 대화형에는 실시간입니다.
- ❌ **"비지도 학습으로 정확한 예측값을 얻는다"** → 공식이 **정밀한 예측을 주지 못한다**고 적습니다. 그 자리는 지도 학습입니다.
- ❌ **"강화 학습은 데이터 편향이 없다"** → **보상을 설계하는 사람의 편향**이 결과에 들어갑니다.
- ❌ **"ML 모델은 같은 입력에 항상 같은 답을 준다"** → ML은 **확률적**입니다. 결정론이 필요한 요구에는 ML이 답이 아닙니다.

## 🧪 자가 점검

**Q1.** 어떤 시스템이 "데이터를 분석해 이탈 가능성이 높은 고객을 분류"합니다. 이것은 GenAI인가요? 판단 기준 한 줄로 답하세요. (→ 2) GenAI와 에이전틱 AI)

<details><summary>정답 보기</summary>

**GenAI가 아닙니다.** 가르는 기준은 **「새 콘텐츠를 만드는가」** 하나입니다. 공식은 GenAI를 "간단한 텍스트 프롬프트로 이미지·비디오·텍스트·오디오 같은 새 콘텐츠와 결과물을 만드는 AI 시스템"으로 정의하고, **"데이터 분석에 한정됐던 과거 AI와 달리"**라고 적습니다. 분류·예측은 전통적인 ML 작업입니다.
</details>

**Q2.** 야간에 쌓인 1,200만 건의 거래 로그를 아침까지 한 번에 채점해야 합니다. 상시 엔드포인트를 두고 싶지 않고 각 결과를 원본 레코드와 짝지어야 합니다. 어떤 추론 유형이고, 인스턴스를 10대로 늘릴 때 주의할 점은? (→ 3) 추론 유형)

<details><summary>정답 보기</summary>

**배치 변환(batch transform)**입니다. 공식이 적는 선택 이유가 그대로 맞습니다 — **대규모 데이터셋에서 추론**, **영구 엔드포인트가 필요 없을 때**, 그리고 **입력 레코드와 추론 결과를 연결**해 결과 해석을 돕는 것.

⚠️ 주의할 점: 배치 변환은 **입력 S3 객체를 키로 분할해 인스턴스에 매핑**합니다. 그래서 **입력 파일이 하나뿐이면 인스턴스를 10대 띄워도 한 대만 처리하고 나머지 9대는 유휴**입니다. 파일을 나누거나 미니 배치로 분할해야 병렬화가 생깁니다.
</details>

**Q3.** 레이블이 2%만 달린 10만 건의 긴 문서가 있습니다. 전량 레이블링은 비용이 과합니다. 어떤 학습 유형이고 중간에 어떤 단계가 들어가나요? (→ 5) 학습 유형)

<details><summary>정답 보기</summary>

**준지도 학습(semi-supervised)**입니다. 공식 서술대로 **소량의 레이블 데이터와 대량의 비레이블 데이터**로 훈련하며, 먼저 레이블 데이터로 알고리즘을 **부분 훈련**한 뒤 그 부분 훈련된 알고리즘이 비레이블 데이터에 레이블을 답니다 — 이 과정을 **의사 레이블링(pseudo-labeling)**이라고 합니다. 그 결과를 섞어 다시 훈련합니다. 공식이 드는 장점이 바로 이 상황입니다: "사람이 읽고 레이블을 달기에는 시간이 너무 드는 긴 문서" 같은 데이터에 유용합니다.
</details>

**Q4.** "우리 FM은 비레이블 데이터로 훈련됐으니 비지도 학습 모델이다"라는 설명을 검토하세요. (→ 5) 학습 유형)

<details><summary>정답 보기</summary>

**부정확합니다.** 공식은 FM이 "광범위한 일반화되고 **비레이블**인 데이터로 훈련된다"고 적지만, 동시에 **"FM은 자기 지도 학습(self-supervised learning)을 사용해 입력 데이터에서 레이블을 만든다"**고 명시합니다. 그리고 그것이 **"지도 또는 비지도 학습을 쓰던 이전 ML 아키텍처와 LLM을 구분하는 특징"**이라고 적습니다. 즉 "비레이블 데이터를 쓴다"는 맞지만 "비지도 학습이다"는 틀립니다.
</details>

**Q5.** 규제 기관에 제출할 금액 계산은 입력이 같으면 **반드시** 같은 값이 나와야 합니다. 이 요구에 ML 모델을 쓰는 것이 적절한가요? 공식 서술을 근거로 답하세요. (→ 6) ML은 왜 확률적인가)

<details><summary>정답 보기</summary>

**적절하지 않습니다.** 공식은 ML 알고리즘이 **관찰과 경험으로 배우므로 본질적으로 확률적**이고, 그래서 "사용자가 이렇게 하면 저렇게 된다"가 **"저렇게 될 확률이 X%다"**로 바뀐다고 적습니다. 결정론적 결과가 요구되는 계산은 규칙 기반 로직의 자리입니다. 같은 판단이 목표 1.2.2 **"AI/ML 솔루션이 적절하지 않은 경우"**의 공식 예 — **"예측 대신 특정 결과가 필요한 상황"** — 과 정확히 맞습니다.
</details>

**Q6.** 복수 응답형 문항에서 정답 3개 중 2개만 골랐습니다. 점수는 어떻게 되나요? 그리고 모르는 문항을 비워 두면? (→ 시험 형식)

<details><summary>정답 보기</summary>

**부분 점수는 없습니다** — 공식은 복수 응답형에서 "문항에 배정된 점수를 받으려면 **정답을 모두 선택**해야 한다"고 적습니다. 순서 배열은 순서까지, 매칭형은 모든 쌍을 맞춰야 득점입니다.

그리고 **답하지 않은 문항은 오답으로 채점되고, 추측에 따른 불이익은 없습니다.** 따라서 모르는 문항도 반드시 표시하고 넘어가는 것이 항상 유리합니다.
</details>
