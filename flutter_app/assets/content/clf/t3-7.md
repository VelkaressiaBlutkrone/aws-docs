# AI/ML·분석 서비스

> **커버하는 공식 Task** — CLF-C02 · 도메인 3 「클라우드 기술 및 서비스」(34%) · **Task 3.7 AI/ML·분석 서비스 식별** (`clf-t3-7`)
> 이 문서는 위 한 Task에 1:1로 매핑됩니다. 시험은 *세부 구현*이 아니라 **"이 시나리오에 맞는 AI/ML 또는 분석 서비스가 무엇인가"**를 묻습니다.

## ✅ 학습 목표 체크리스트

이 문서를 끝내면 다음을 스스로 설명할 수 있어야 합니다. (공식 시험 가이드 Task 3.7의 Skill 항목)

- [ ] **AI/ML 3종 — SageMaker(모델 구축) · Lex(챗봇) · Kendra(검색)**의 역할을 구분할 수 있다
- [ ] **분석 4종 — Athena(SQL 쿼리) · Kinesis(실시간 스트리밍) · Glue(ETL) · QuickSight(BI 시각화)**를 구분할 수 있다
- [ ] "챗봇 / 문서 검색 / 커스텀 ML 모델" 같은 단서로 AI 서비스를 고를 수 있다
- [ ] "S3를 SQL로 / 실시간 / ETL / 대시보드" 같은 단서로 분석 서비스를 고를 수 있다

## 🎯 왜 중요한가

- 도메인 3(34%)에서 이 Task는 **서비스 이름 매칭**이 거의 전부입니다. 각 서비스가 *한 문장으로 무엇을 하는지*만 분명하면 풀립니다.
- 두 묶음으로 외우면 쉽습니다: **AI/ML(SageMaker·Lex·Kendra)**와 **분석(Athena·Kinesis·Glue·QuickSight)**. 각 묶음 안에서 *역할이 겹치지 않으니* 키워드로 1:1 매칭됩니다.
- 시험은 깊은 ML 지식을 요구하지 않습니다 — *"챗봇이면 Lex"* 수준의 식별이면 충분합니다.

## 📖 핵심 개념

### 1) AI/ML 서비스 3종 — SageMaker · Lex · Kendra

| 서비스 | 한 줄 역할 | 떠올릴 키워드 |
|---|---|---|
| **Amazon SageMaker (AI)** | **ML 모델을 구축·훈련·배포**하는 완전관리형 ML 서비스(데이터 과학자·개발자용) | "*커스텀* 머신러닝 모델", "모델 훈련·배포" |
| **Amazon Lex** | **음성·텍스트 대화형 인터페이스(챗봇)** 구축 — 자동 음성 인식(ASR) + 자연어 이해(NLU) | "*챗봇*", "음성봇", "대화형 인터페이스" |
| **Amazon Kendra** | **지능형 엔터프라이즈 검색** — ML·자연어로 문서/콘텐츠에서 의미 기반 검색 | "*문서/콘텐츠 검색*", "엔터프라이즈 검색" |

> 한 문장 구분: **SageMaker는 *모델을 만든다*, Lex는 *대화한다(챗봇)*, Kendra는 *찾는다(검색)*.**
> ℹ️ 정직성 메모: Amazon SageMaker는 2024-12 **Amazon SageMaker AI**로 이름이 바뀌었습니다(ML 구축·훈련·배포 기능). 기존 'SageMaker'는 데이터·분석·AI 통합 플랫폼 명칭으로 확장됐습니다. CLF에선 "ML 모델 구축·훈련·배포 = SageMaker(AI)"로 기억하면 됩니다.

### 2) 분석 서비스 4종 — Athena · Kinesis · Glue · QuickSight

| 서비스 | 한 줄 역할 | 떠올릴 키워드 |
|---|---|---|
| **Amazon Athena** | **Amazon S3의 데이터를 표준 SQL로 직접 쿼리**(서버리스, 쿼리당 과금) | "*S3를 SQL로*", "서버리스 쿼리", "임시(ad-hoc) 분석" |
| **Amazon Kinesis** | **실시간 스트리밍 데이터**를 대규모로 수집·처리 | "*실시간*", "스트리밍", "로그·클릭스트림 실시간" |
| **AWS Glue** | **서버리스 데이터 통합 — ETL(추출·변환·적재)** 파이프라인, 데이터 카탈로그 | "*ETL*", "데이터 준비·통합", "데이터 카탈로그" |
| **Amazon QuickSight** | **클라우드 BI — 대화형 대시보드·시각화** | "*대시보드*", "시각화", "비즈니스 인텔리전스(BI)" |

> 한 문장 구분:
> - **Athena = S3를 *SQL로 묻는다*(쿼리).**
> - **Kinesis = *실시간으로 흘려보낸다*(스트리밍).**
> - **Glue = *모아서 정제·변환한다*(ETL).**
> - **QuickSight = *보기 좋게 그린다*(대시보드·BI).**

> ℹ️ 정직성 메모: Amazon QuickSight는 **Amazon Quick**으로 진화하면서 BI 기능이 **Amazon Quick Sight**로 이어집니다(기존 QuickSight API·SDK는 그대로 동작). CLF에선 "대시보드·시각화·BI = QuickSight"로 기억하면 됩니다.

### 3) 한눈에 — 시나리오 → 서비스

| 시나리오 | 서비스 |
|---|---|
| 고객 문의에 답하는 음성/문자 **챗봇** | **Lex** |
| 회사 문서를 자연어로 **검색** | **Kendra** |
| 데이터로 **커스텀 ML 모델**을 훈련·배포 | **SageMaker (AI)** |
| **S3에 쌓인 로그**를 SQL로 즉석 분석 | **Athena** |
| 클릭스트림·로그를 **실시간**으로 수집·처리 | **Kinesis** |
| 여러 소스 데이터를 **정제·변환(ETL)** | **Glue** |
| 분석 결과를 **대시보드로 시각화** | **QuickSight** |

### 언어 AI — Amazon Translate · Amazon Transcribe (보강)

- **Amazon Translate**: 텍스트를 여러 언어로 **자동 번역**하는 신경망 기계 번역 서비스.
- **Amazon Transcribe**: **음성을 텍스트로** 변환하는 자동 음성 인식(ASR). 통화·녹음을 텍스트화해 검색·분석에 활용 — 텍스트를 음성으로 만드는 **Amazon Polly**의 반대 방향입니다.

> 시험 신호: "여러 언어로 번역" → **Translate**, "음성 → 텍스트" → **Transcribe**, "텍스트 → 음성" → **Polly**.
> 출처: [Amazon Translate](https://docs.aws.amazon.com/translate/latest/dg/what-is.html), [Amazon Transcribe](https://docs.aws.amazon.com/transcribe/latest/dg/what-is.html)

## ✍️ 시험 포인트

- **챗봇/대화형 = Lex.** **문서·엔터프라이즈 검색 = Kendra.** **커스텀 ML 모델 구축·훈련·배포 = SageMaker(AI).**
- **S3를 SQL로 쿼리 = Athena**(서버리스). **실시간 스트리밍 = Kinesis.**
- **ETL/데이터 통합·준비 = Glue**(서버리스). **대시보드·시각화·BI = QuickSight.**
- 분석 흐름이 함께 나오면: **Kinesis(실시간 수집) → Glue(ETL) → Athena/QuickSight(쿼리·시각화)** 식으로 역할이 이어집니다.
- 깊은 ML 지식 불필요 — *한 줄 역할*로 매칭.

---

## ⚠️ 흔한 함정

1. **"챗봇을 만들려면 SageMaker를 쓴다."** → ❌. 대화형 챗봇은 **Lex**. SageMaker는 *커스텀 ML 모델* 구축·훈련·배포.
2. **"문서 검색도 Lex로 한다."** → ❌. 자연어 **검색**은 **Kendra**. Lex는 *대화(챗봇)*.
3. **"S3 데이터를 분석하려면 먼저 DB로 옮겨야 한다."** → ⚠️ 불필요. **Athena**로 S3를 *그 자리에서* 표준 SQL로 쿼리(서버리스).
4. **"Glue로 대시보드를 만든다."** → ❌. 시각화·대시보드는 **QuickSight**. Glue는 *ETL(데이터 준비)*.
5. **"실시간 스트리밍을 Athena로 처리한다."** → ❌. 실시간 스트리밍 수집·처리는 **Kinesis**. Athena는 *저장된 데이터의 SQL 쿼리*.
6. **"QuickSight로 데이터를 변환·정제한다."** → ❌. 변환·정제(ETL)는 **Glue**. QuickSight는 *시각화(BI)*.

## 🧪 자가 점검

> 아래는 학습용 자가 점검입니다. (정식 검증 문항은 `t3-7.questions.json` 참조)

**Q1.** 고객 문의에 음성·문자로 응답하는 챗봇을 만들려면? 그리고 회사 내부 문서를 자연어로 검색하게 하려면?

<details><summary>정답 보기</summary>

챗봇은 **Amazon Lex**(음성·텍스트 대화형, ASR+NLU). 자연어 문서 검색은 **Amazon Kendra**(지능형 엔터프라이즈 검색).
</details>

**Q2.** 데이터로 직접 머신러닝 모델을 구축·훈련하고 운영 환경에 배포하려면 어떤 서비스인가요?

<details><summary>정답 보기</summary>

**Amazon SageMaker (AI)**. 데이터 과학자·개발자가 ML 모델을 구축·훈련·배포하는 완전관리형 ML 서비스입니다.
</details>

**Q3.** Amazon S3에 저장된 로그 데이터를, 별도 인프라 없이 표준 SQL로 즉석에서 분석하려면? 그리고 클릭스트림을 실시간으로 수집·처리하려면?

<details><summary>정답 보기</summary>

S3를 SQL로 쿼리하는 것은 **Amazon Athena**(서버리스). 실시간 스트리밍 수집·처리는 **Amazon Kinesis**입니다.
</details>

**Q4.** 여러 소스의 데이터를 추출·변환·적재(ETL)해 분석용으로 준비하려면? 그리고 그 결과를 대화형 대시보드로 시각화하려면?

<details><summary>정답 보기</summary>

ETL·데이터 통합은 **AWS Glue**(서버리스). 대시보드 시각화·BI는 **Amazon QuickSight**입니다.
</details>
