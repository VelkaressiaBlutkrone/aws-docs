# 결제·예산·비용 관리 도구

## 🎯 왜 중요한가

- 도메인 4(12%)의 이 Task는 **"비용 관리 도구 이름 매칭"**입니다. 시험은 *시점*으로 도구를 가릅니다: 만들기 *전*엔 추정(Pricing Calculator), 만든 *후*엔 분석(Cost Explorer)·통제(Budgets).
- **Organizations = 통합 결제 + 다계정 거버넌스**도 단골입니다.

## 📖 핵심 개념

### 1) 비용을 다루는 도구 — 시점으로 구분 (★ 시험 핵심)

| 도구 | 무엇 | 시점 |
|---|---|---|
| **AWS Pricing Calculator** | AWS 사용 **비용을 *구축 전*에 추정**(견적). 무료 웹 도구 | 만들기 **전**(예측·계획) |
| **AWS Cost Explorer** | **발생한 비용·사용량을 시각화·분석**(과거 ~13개월, 향후 ~18개월 예측) | 만든 **후**(분석) |
| **AWS Budgets** | **예산을 설정**하고 임계값을 초과(또는 초과 예상) 시 **알림** | 운영 중(통제·알림) |

> 한 문장 구분:
> - **Pricing Calculator = "쓰기 전에 얼마 들까?"**(추정).
> - **Cost Explorer = "지금까지 얼마 썼고 추세는?"**(분석·시각화).
> - **Budgets = "이 선을 넘으면 알려줘"**(예산·알림).

### 2) AWS Organizations — 다계정 중앙 관리 + 통합 결제

**AWS Organizations**는 여러 AWS 계정을 **중앙에서 관리·거버넌스**합니다.

- **통합 결제(consolidated billing):** 조직의 모든 계정을 **하나의 청구서·단일 결제 수단**으로. 사용량을 합쳐 **볼륨 할인**도 받을 수 있음.
- **조직 단위(OU):** 계정을 그룹으로 묶어 정책을 일괄 적용.
- **서비스 제어 정책(SCP):** 조직 내 계정·사용자가 *할 수 있는 작업(서비스·리전)*을 중앙에서 통제(거버넌스).

> 시험 신호: **"여러 계정을 하나로 결제·중앙 관리·정책 통제"** → Organizations(통합 결제·SCP·OU).

### 3) 비용 추적 — 비용 할당 태그와 CUR

- **비용 할당 태그(Cost Allocation Tags):** 리소스에 *태그*(예: `프로젝트=A`, `팀=마케팅`)를 붙여, **태그별로 비용을 분류·집계**합니다.
- **Cost and Usage Report(CUR):** 가장 **상세한 비용·사용량 보고서**(어떤 리소스에 얼마가 들었는지 세부 데이터).

> 시험 신호: **"비용을 프로젝트·팀별로 나눠 보고 싶다"** → **비용 할당 태그**. **"가장 상세한 비용 데이터"** → **CUR**.

### 이상 탐지와 비용 예측 — Cost Anomaly Detection · Cost Explorer forecast (보강)

- **AWS Cost Anomaly Detection**: **머신러닝**으로 평소와 다른 **비정상 지출을 자동 탐지**하고 알림을 보냅니다. (Budgets는 사용자가 정한 *임계값* 기반 알림 — 둘은 보완 관계.)
- **AWS Cost Explorer 예측(forecast)**: 과거 비용·사용량 추세를 바탕으로 **향후 비용을 예측**·시각화합니다.

> 시험 신호: "ML로 비정상 지출 탐지" → **Cost Anomaly Detection**, "임계값 알림" → **Budgets**, "추세 기반 미래 비용 예측" → **Cost Explorer**.
> 출처: [Cost Anomaly Detection](https://docs.aws.amazon.com/cost-management/latest/userguide/getting-started-ad.html), [Cost Explorer](https://docs.aws.amazon.com/cost-management/latest/userguide/ce-what-is.html)

## ✍️ 시험 포인트

- **Pricing Calculator = 구축 *전* 비용 추정**(견적). **Cost Explorer = 발생 비용 *분석*·시각화·예측**.
- **AWS Budgets = 예산 설정 + 임계값 초과 *알림***(SNS/이메일).
- **AWS Organizations = 다계정 중앙 관리 + 통합 결제(단일 청구·볼륨 할인) + SCP(거버넌스)·OU**.
- **비용 할당 태그 = 태그별 비용 분류.** **CUR = 가장 상세한 비용·사용량 보고서.**

---

## ⚠️ 흔한 함정

1. **"Cost Explorer로 구축 전 비용을 추정한다."** → ❌. 구축 *전* 추정은 **Pricing Calculator**. Cost Explorer는 *이미 발생한* 비용 분석.
2. **"Budgets로 과거 비용을 자세히 분석한다."** → ⚠️ Budgets는 *예산·알림*이 주목적. 과거 분석·시각화는 **Cost Explorer**.
3. **"통합 결제는 Cost Explorer 기능이다."** → ❌. 다계정 **통합 결제(consolidated billing)**는 **AWS Organizations**.
4. **"SCP는 비용 절감 도구다."** → ❌. SCP는 *거버넌스*(허용 작업 통제)입니다. 비용 분석은 Cost Explorer, 예산은 Budgets.
5. **"태그는 비용과 무관하다."** → ❌. **비용 할당 태그**로 프로젝트·팀별 비용을 분류·추적합니다.

## 🧪 자가 점검

> 아래는 학습용 자가 점검입니다. (정식 검증 문항은 `t4-2.questions.json` 참조)

**Q1.** 아직 구축하지 않은 아키텍처의 예상 비용을 미리 견적 내려면 어떤 도구인가요? 그리고 이미 발생한 비용의 추세를 시각화·분석하려면?

<details><summary>정답 보기</summary>

구축 전 비용 추정은 **AWS Pricing Calculator**, 발생한 비용의 시각화·분석은 **AWS Cost Explorer**입니다.
</details>

**Q2.** 월 비용이 정한 금액을 넘거나 넘을 것으로 예상되면 알림을 받으려면 어떤 서비스인가요?

<details><summary>정답 보기</summary>

**AWS Budgets**. 비용·사용량 예산을 설정하고 임계값을 초과하거나 초과가 예상되면 이메일·SNS로 알림을 보냅니다.
</details>

**Q3.** 여러 AWS 계정을 하나의 청구서로 통합 결제하고, 계정들을 중앙에서 정책으로 거버넌스하려면 어떤 서비스인가요?

<details><summary>정답 보기</summary>

**AWS Organizations**. 통합 결제(단일 청구·볼륨 할인)와 조직 단위(OU)·서비스 제어 정책(SCP)을 통한 다계정 중앙 관리·거버넌스를 제공합니다.
</details>

**Q4.** 비용을 프로젝트별·팀별로 나누어 추적하려면 무엇을 활용하나요?

<details><summary>정답 보기</summary>

**비용 할당 태그(Cost Allocation Tags)**. 리소스에 태그를 붙여 태그별로 비용을 분류·집계합니다. 가장 상세한 데이터는 **Cost and Usage Report(CUR)**로 얻습니다.
</details>
