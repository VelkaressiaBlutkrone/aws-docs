  고객"** 전제를 명시해 해소. AWS 공식이 보장하는 경우라 억지 전제가 아니다
  ("will not impact customers currently using AWS Snowball Edge … data migration needs").

  "available only to AWS Enterprise Support customers at this time" — 무조건적 정답으로
  두면 숨은 전제를 교체하는 데 그친다. 게다가 본인 저장장치를 AWS 시설(LA·NY)로 직접
  가져가는 방식이라 stem 의 온프레미스 NAS 시나리오와 어긋난다. md:306 자체가 "보기로
  등장하면 기존 고객 맥락으로 읽는다"고 이 읽기를 승인한다.
- 사람이 달리 본다면 `options[0]` 서비스만 DTT 로 교체하면 된다(인덱스 불변). PR 본문에 적음.
