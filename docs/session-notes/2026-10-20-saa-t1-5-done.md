## 다른 세션이 알아야 할 것

1. **문서 정정이 파생 문항에 전파되지 않는 구조적 결함**이 이 레포에 있다. `saa-t1-5.md` 는
   2026-10-19에 8건 정정됐는데 `saa-t1-5.questions.json` 은 구식 사본으로 남아 있었다.
   **다른 Task를 검수할 때 md 끝의 정정 로그를 먼저 읽고 그 항목이 문항에 반영됐는지
   대조**하면 결함을 빨리 찾는다. (t1-1·t1-2·t1-3·t1-4 등 2026-10-19 정정 대상 문서 전부
   같은 위험이 있다 — 이번 작업 범위 밖이라 확인하지 않았다. **후속 후보.**)
2. **`concepts.html#enveloping` 앵커는 현재 존재하지 않는다.** 봉투 암호화는
   `kms/latest/developerguide/kms-cryptography.html` 로 옮겨졌다. 4KB 상한의 공식 출처는
   `kms/latest/cryptographic-details/encrypt-operation.html`.
3. **"KMS는 멀티테넌트라 AWS가 키에 접근한다"는 근거를 쓰면 안 된다.** AWS는 모든 키
   저장소가 "AWS 운영자를 포함해 누구도 평문 키에 접근하지 못하게" 설계됐다고 명시한다
   (`prescriptive-guidance/.../key-management.html`). KMS vs CloudHSM 갈림길은 **단일
   테넌트**다 — 공식 표현은 "tenant-agnostic fleet of HSMs"
   (`kms/.../key-store-overview.html`). 다른 도메인에서 같은 비교가 나오면 이 축을 쓸 것.
4. **파일 줄바꿈은 CRLF다** (`core.autocrlf=true`). Git Bash 의
   `head -c N file | grep -q $'\r'` 체크는 **거짓으로 LF를 보고했다** — Python 으로
   `raw.count(b'\r\n')` 을 세야 맞다. JSON 치환 스크립트는 메모리에서 LF로 다루고
   `newline='\r\n'` 으로 되돌려 써야 전체 재포맷을 피한다(`sources` 1줄 compact 포맷 보존).
5. **가드 단정에 날짜·문장을 리터럴로 못박지 말 것.** `saa_t12_t13_facts_test.dart` 가
   `lastVerified: 2026-10-19` 를 `isTrue` 로 고정해 둬서 md 를 갱신하자마자 그 테스트가
   먼저 터졌다. 날짜 하한 비교로 바꿔 뒀다(되돌아가는 것만 금지). 같은 교훈이
   `saa-t1-4-q10` 에도 있다.
