- 5개 문서(t1-1, t1-2, t1-3, t1-4, t2-1)를 전문 정독. 전반적 사실 정확도는 높음 — 클라우드 정의(온디맨드+종량 과금), WAF 6대 기둥 이름·정의·2021년 지속 가능성 추가, CAF 6관점·이점(ESG 포함), DMS(CDC·SCT)/Snowball/DataSync 구분, 7R 명칭, CapEx→OpEx, Compute Optimizer(rightsizing·유휴 식별), BYOL·Dedicated Hosts, 공동 책임 경계(of/in, 공유 통제 3종, EC2/RDS/Lambda 이동, S3 기본 암호화 2023-01)까지 모두 공식 문구와 부합함을 확인.
- t1-1·t1-2·t1-3은 보고할 발견 없음. t2-1의 "공식 문서 원문" 인용("Security in the cloud — Your responsibility is determined by the AWS service that you use.")은 실제로 인용 출처(각 서비스 Security 챕터 보일러플레이트)와 일치해 문제 아님.
- 발견 3건: M 1건(t2-1 — "도메인 2가 시험 비중 가장 큼" 단정은 오류, 최대는 도메인 3의 34%), L 2건(t1-4 관리형 서비스 예시에 ECS·EKS를 묶어 "패치를 AWS가 대신"으로 일반화, t2-1 용어표의 서버리스 정의가 FaaS로 협소). H(시험 오답 직결) 발견 없음.
- 샤드 내 문서 간 직접 모순은 없음. 단 t1-4의 ECS·EKS 패치 일반화는 t2-1의 "서비스에 따른 책임 이동" 원칙과 미묘한 긴장이 있어 DOC-CLF-001에 병기.
