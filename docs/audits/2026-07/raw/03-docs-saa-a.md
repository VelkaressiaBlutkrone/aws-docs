# ③ 학습문서 사실성 감사 샤드 — 03-docs-saa-a (t1-1~t1-5) — 2026-07

## 요약 (3~5줄)

- 대상: SAA 도메인 1(보안 아키텍처) 학습문서 5건(saa-t1-1 ~ t1-5) 전문 정독. 총 **발견 15건** (H 2 · M 4 · L 9), 사실의심 Y 14건.
- 시험 오답 유발 가능(H) 2건: **NAT 게이트웨이 "자동 고가용성"**(실제는 단일 AZ 내 이중화 — AZ별 배치가 단골 출제)과 **"Interface Endpoint는 S3·DynamoDB 외"**(S3는 2021년, DynamoDB는 2024년부터 Interface 지원 — 온프레미스→S3 사설 접근 문항에서 오답 유도, 문서 내 Q3 답변과도 모순).
- M 4건: KMS "IAM 정책·키 정책 교집합" 일반화(키 정책 단독 허용 가능 — t1-1 리소스 정책 원리와도 모순), WAF×CloudFront "us-east-1 제한 없음"(실제는 CLOUDFRONT 스코프 웹 ACL을 us-east-1에서 생성), t1-2 Q1 질문(us-east-1)·답변(ap-northeast-2) 리전 불일치, t1-1 SCP 관리 계정 예외를 "루트만"으로 축소 서술.
- 나머지는 자구·보수적 수치 확인 건(WAF Count 비종결 액션, Vault Lock 쿨다운 "기본 3일", AWS Backup 지원 목록의 EKS 등). 전반적으로 SG/NACL 상태성, SCP 평가, 봉투 암호화, ACM us-east-1 등 핵심 시험 포인트는 정확했다.

## 비고 (오류 아님 — 검증 통과 확인 메모)

- SG(Stateful·Allow 전용·ENI 단위) vs NACL(Stateless·Allow/Deny·번호순) 비교, 서브넷 5개 예약 IP 내역, SCP 누적 교집합·전체 기능 모드 요건·서비스 연결 역할 예외, 봉투 암호화 4KB 한도, AWS 관리형 키 연 1회 자동 교체, ACM us-east-1 제약, Secrets Manager 64KB/Parameter Store 4·8KB, STS 기본 1시간·최대 12시간, OU 최대 5단계, NAT GW 최대 100Gbps 등 핵심 수치·경계 서술은 현행 공식 문서와 일치함을 확인.
- t1-4 WAF 보호 리소스 7종 목록(CloudFront·ALB·API GW REST·AppSync·Cognito UP·App Runner·Verified Access)은 정확(이후 추가된 리소스 누락은 오류로 보지 않음).
