# ③ 학습문서 사실성 감사 샤드 — 03-docs-clf-c (t3-3~t3-7) — 2026-07

## 요약 (3~5줄)

- t3-3(컴퓨팅)·t3-4(DB)·t3-5(네트워크)·t3-6(스토리지)·t3-7(AI/ML·분석) 5개 문서 전문 정독. 전반적으로 공식 문서와 잘 정렬되어 있고, 서비스 구분·시험 신호는 CLF-C02 정답 관례와 일치. **H(시험 오답 직접 유발)급 발견 없음.**
- 사실의심 5건: DynamoDB "트래픽 없으면 비용 없음"(스토리지 과금 누락), EBS "종료해도 데이터 유지"(루트 볼륨 기본 삭제와 상충), 11 9s 내구성 용어풀이의 기간(1만 년) 누락으로 의미 왜곡, "가상 서버를 늘리고(scale up)"의 수평/수직 스케일링 용어 오매핑, Storage Gateway 유형에 FSx File Gateway 신규 고객 중단 미주석.
- 문서 내 상호 모순 1건: 흔한 함정의 "원리: §N" 각주 번호가 무번호 보강 절과 불일치(t3-3·t3-5·t3-7 공통 패턴).
- 잘된 점(참고): Forecast 신규 중단·SageMaker AI 개명·QuickSight→Quick Sight 리브랜드는 정직성 메모로 이미 정확히 처리됨. Aurora 5x/3x, Lambda 15분, RDS 엔진 목록(Db2 포함), ElastiCache 엔진(Valkey/Memcached/Redis OSS), S3 클래스 트레이드오프, 보안 그룹 vs NACL, Direct Connect vs VPN 모두 공식 문서와 일치 확인.
- Phase 표기 해석(지시문에 정의 없음): **A = 사실 정정 우선 반영**, **B = 2단 검증·후속 보강 처리**로 표기했다.
