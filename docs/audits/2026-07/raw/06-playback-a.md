# ⑥ 오디오 재생 코드 감사 샤드 — 06-playback-a (런타임·상태기계) — 2026-07

## 요약 (3~5줄)
재생 상태기계(`AudioController`)·플레이리스트(`LecturePlaylist`)·런타임 경계·MediaSession 바인딩·백엔드(`WebAudioBackend`)를 정독했다. 리스너/타이머 짝맞춤·조건부 import 경계·play() await-금지 패턴·핫리스타트 element 재사용은 **모두 정상**으로 확인했다(01-code-b의 "미해제 없음" 판정을 재생 특화 경로에서 재확인). 재생 특화 관점에서 새로 발견한 것은 주로 **오류 복구 공백**(error/stalled 상태에서 재시도 경로 부재 — 무한 로딩·죽은 컨트롤러 가능성)과 **openDoc 비중단 계약의 부작용**(재생 중 다른 문서 진입 시 미니플레이어 제목이 실제 보는 문서와 불일치)이다. 상태기계 전이 자체는 견고하며 ended 이중전진 가드도 유효하다. H(재생불능·크래시)급 확정 버그는 없고, 발견은 M/L(오류 복구 하드닝·방어 보강) 위주다.
