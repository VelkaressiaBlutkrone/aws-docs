- SOA 도메인 4b+5(보안·네트워킹) 6개 문서 전문 정독. 발견 16건: **H 1 / M 10 / L 5**, 사실의심(Y) 15건.
- 최중대(H): soa-t5-4가 "SG 거부는 Flow Log에 REJECT로 안 남는다"를 ★결정적 뉘앙스로 문서 전반(체크리스트·§2~§3·시험 포인트·함정·Q1)에 반복 교육 — AWS 공식 정의는 REJECT="SG **또는** NACL이 불허", 공식 예시는 SG 인바운드 불허 시 단일 REJECT 레코드 기록을 명시. 추론 패턴("REJECT 부재=SG 의심")이 역방향 오류라 시험 오답에 직결, §3 전면 재작성 필요.
