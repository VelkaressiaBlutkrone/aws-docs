# ⑥ 오디오 재생 코드 감사 샤드 — 06-playback-b (위젯·UI·자산 전송) — 2026-07

## 요약 (3~5줄)
CLF 오디오 강의 UI(허브·cert 페이지·미니플레이어·트랜스포트 바·진행바)와 자산 전송 계층을 정독했다. 위젯 UI는 대체로 DESIGN.md 규율(InkWell+FocusRing·context.c 토큰·합니다체·Tooltip/semanticLabel)을 잘 지킨다. **가장 실질적인 발견은 잠금화면(MediaSession) 메타 정합 결함**: `setNowPlaying`(제목)이 `study_doc_page`의 문서 열람 1곳에서만 호출돼, 트랜스포트 바의 next/prev/first/last·autoAll 자동전환·CertAudioPage 행 탭으로 트랙이 바뀌어도 잠금화면 제목이 갱신되지 않는다(앱 내 미니플레이어/트랜스포트 카피는 정상 갱신). 자산 전송 측면에서는 **19개 mp3 총 174.3MB가 pubspec `assets:`로 앱 번들에 포함**되나, `<audio>.preload='metadata'`라 초기 페이지 로드나 최초 프레임에는 mp3 본문이 fetch되지 않고 재생 트랙만 지연 로드된다(초기 로드 영향은 없음 — 번들 크기·서비스워커 부재로 반복 방문 시 재다운로드가 관심사). index.html에는 mp3 preload 태그나 즉시 fetch가 없다. 상태 카피·경계 처리·접근성은 전반적으로 견고하며 접근성 위반은 발견되지 않았다.
