# 슬라이드 강의 P0 · 슬라이드 우선 시험 기록 (2026-11-23)

> **결론:** 기존 음성에 슬라이드를 맞추는 방식은 청취에서 불합격했다. 슬라이드를 먼저 만들고 전용 대본을 입히는 방식은 사용자 평가 **100점 만점에 80점**으로 통과했다. 사용자 판단으로 **지금은 기록만 하고** 설계 개정과 구현은 하지 않는다.

## 1. 시험한 방식과 결과

| 시험 | 방식 | 결과 |
|---|---|---|
| P0 1차 | `saa-t3-7` 기존 음성 + 문서 문장 슬라이드 | 청취 10곳 전부 어긋남 |
| P0 2차 | 같은 음성 + 굵은 구절 요점 슬라이드, 전환 지연 0~1초 선택 | 청취 10곳 전부 어긋남 |
| 슬라이드 우선 | `Alias vs CNAME` 6장 18단계, 전용 대본, 2분 28초 | **통과, 80/100** |

사용자 평가(슬라이드 우선): 「화면의 흐름과 음성의 싱크 및 내용은 괜찮음. 화면 퀄리티만 이후 업그레이드할 수 있으면 좋을지도.」

P0 2차에서 사용자가 꼽은 문제는 넷이다.

- 보여지는 내용 대비 음성이 짧아 판단이 힘들다(표본이 15초 조각이었다).
- 전환 시점이 맞지 않는다.
- 요점 내용이 부적절하다.
- 강의처럼 느껴지지 않는다.

## 2. 측정값

**기존 음성의 시각 정확도(`saa-t3-7`, 50분 6초).** 기계 기준은 통과했지만 청취는 불합격이었다.

| 항목 | 값 |
|---|---|
| Polly 요청 | 22,162자, 약 $0.355 |
| 제목 시작과 mp3 무음 | 최대 0.115초 |
| 발화 큐 | 82/82, 시간순 |
| 문장 시작과 무음 끝 | 489문장 중 97.3%가 0.12초 이내, 최대 0.303초 |
| 대조군(0.7초 이동) | 0.12초 이내 비율 1.0%·0.2% |

- 긴 구간의 두 번째 조각은 길이 비례로 맞추면 최대 0.87초 어긋났고, 조각 시작을 mp3 무음에 정렬해야 위 값이 나왔다.
- **기계 정확도는 체감 품질을 보장하지 않는다.** 이 시험의 핵심 교훈이다.

**슬라이드 우선 시험.** 1,008자, Polly 약 $0.02. 단계별로 따로 합성하므로 전환 시각이 실측값이고 speech marks 가 필요 없다.

## 3. 원인 판단

기존 음성은 화면 없이 들어도 이해되도록 쓴 대본이다. 나중에 화면을 붙이면 읽기와 듣기가 경쟁한다. 인강은 화면을 먼저 설계하고 강사가 그 화면을 가리키며 말한다.

## 4. 개정할 때 지킬 것

- 음성 강의(이어폰 자기학습)와 슬라이드 강의는 **별도 콘텐츠**다.
- 굵은 구절을 기계로 요점화하지 않는다. 숫자만 남거나 함정 문단의 **틀린 주장이 요점으로 뽑힌다.**
- 전용 대본은 새 콘텐츠이므로 사실 검증과 사람 청취가 다시 필요하다.
- 시험은 짧은 조각이 아니라 **한 주제를 처음부터 끝까지** 듣는 형태로 한다.

## 5. 개정 때 정할 것

1. 제작 단위: 문서 전체 한 강의 또는 주제별 2~5분 강의(제안은 주제별).
2. 시범 범위: 전 자격증 전에 한 문서부터.
3. 화면 품질: 다이어그램·표·강조를 `DESIGN.md` 기준 장면 유형으로 정리.

## 6. 산출물

- [`slide_first.py`](slide_first.py): 시험 강의의 슬라이드·대본·합성·재생 페이지 생성 스크립트. 시험용이고 앱 코드가 아니다. 실행하면 Polly 를 호출하고 같은 폴더에 캐시와 mp3·html 을 쓰므로 **레포 밖으로 복사해 실행한다.**
- 생성된 mp3·html 과 P0 표본은 임시 폴더에만 있어 보존되지 않는다.
