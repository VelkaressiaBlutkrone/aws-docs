## 2. 컨트롤러 검증

- 소유 경계: 다섯 세션이 만든 변경은 보고서 다섯 편뿐이다(`git status` 실측). 대본·문서·코드 변경 0.
- 항목 표제를 기계로 파싱해 **344건**의 세그먼트 실재와 인용을 대조했다. 세그먼트 누락은 0건이다.
- 인용 불일치는 발화 13건(전부 R3) · 문서 6건(전부 R1)이다. 말줄임·표 조각 때문일 수 있으나 **확인하지 않았으므로 해당 항목은 적용 전에 다시 판정한다.**
- 무작위 R1 표본 7건은 전부 실제 사실 충돌로 읽혔다. 공식 AWS 문서 대조는 일부 항목만 이뤄졌고, 판정의 기준은 현재 학습문서다.

## 3. 대본보다 먼저 닫아야 하는 것

1. **학습문서 자체의 잔여 오류·내부 모순.** 세션들이 약 30건을 제기했다(미판정). 13개 문구는 해당 줄에 실재함을 확인했다. 예: `saa-t1-2.md:116` 루트 MFA 유예 35일(같은 트랙 `saa-t1-1`은 14일로 정정) · `saa-t2-5.md:199` DRS 「추가 에이전트 없이」 · `saa-t2-5.md:133` Aurora 「1분 내 승격」 · `saa-t3-2.md:419` Lustre 「수백만 IOPS」 · `clf/t4-1.md:114` 절 번호 오기. **발화를 문서에 맞추기 전에 문서를 공식과 대조해 고친다.**
2. **코드 블록이 대본에 들어오지 않는다.** 세그먼트 종류에 코드 블록이 없어 「하나씩 살펴보겠습니다」로 예고만 하고 내용이 빠지는 자리가 생긴다.
3. **발음사전 공백.** `Organizations`·`Route 53`·`ElastiCache`·`EventBridge`·`Step Functions` 같은 서비스 이름이 사전에 없어 한 강의 안에서 표기가 갈린다. 대본마다 고치지 않고 사전에서 닫는다.
4. **기존 `generate`는 강의체 문장을 지운다.** 바뀐 세그먼트만 교체하고 새 절과 챕터를 넣는 동기화 경로가 필요하다.
5. **`saa-t4-2`~`t4-5`는 풍부화 전 대본이다.** 세그먼트 패치보다 현재 문서에서 재생성하는 쪽이 맞다는 보고이며, 음성이 없어 라이브 영향은 없다.
