## 2. 대본의 설계 — 먼저 이해한다

대본은 학습문서의 **강의체 확장판**이다. 문장이 문서와 다른 것은 **결함이 아니다.**

- 허용: 대화체 풀이, 짧은 비유·예시, 연결 문장, 표의 요약
- 불변식: 원문의 약어·수치·핵심 주장 보존, **원문에 없는 새 시험 사실 단정 금지**
- 표기: 음성용 평문이다. `EC2`를 「이씨투」로 적는 것은 정상이다. 기호·URL·마크다운은 쓰지 않는다

**실제로 발화되는 본문**은 세그먼트마다 다음 우선순위로 읽는다.

1. `skip: true` → 발화되지 않는다(검수 대상 아님)
2. `kind == "table"` → `audioSummary`
3. 그 외 → `enrichedScriptText`, 없으면 `scriptText`

`sourceExcerpt`는 **발화되지 않는다.** 합성 당시의 원문 조각이므로 현재 문서와의 차이를 찾는 단서로 쓴다.

## 3. 검수 축과 등급

| 코드 | 뜻 | 조치 |
|---|---|---|
| **R1 사실 충돌** | 발화가 **현재 학습문서**와 모순된다(정정 전 사실이 남아 있다) | 반드시 수정 |
| **R2 사실 추가** | 확장 문장이 학습문서에 없는 시험 사실을 단정하거나 틀렸다 | 수정 또는 삭제 |
| **R3 중요 누락** | 합성 뒤 문서에 추가된 **시험에 중요한 사실·절**이 발화에 없다 | 보강 후보 |
| **R4 상태 누락** | 문서가 적는 서비스 종료·유지 관리·범위 외 메모가 발화에 없다 | 문서당 첫 언급에 한 번 |
| **R5 발화 품질** | 발음 오류, 잘못 읽히는 표기, 어색한 문장, 기호 잔존 | 수정 후보 |
| **N 수정 불필요** | 표기 정리·평문화·문장 다듬기만 달라 발화 사실이 같다 | 건수만 적는다 |

⚠️ **R1과 N을 구별하는 것이 이 검수의 핵심이다.** `sourceExcerpt`와 현재 문서의 글자 차이는
대부분 N이다. 문서를 고쳤다는 이유만으로 발화를 고치지 않는다.

⚠️ 문서가 옳다고 전제하되, **문서 자체가 틀려 보이면** 고치지 말고 `## 컨트롤러 요청`에 적는다.

⚠️ R2·R1을 판정할 때 공식 AWS 문서를 확인했다면 URL과 **짧은 인용**을 적는다. 「공식에 없다」는
추출 방법 둘과 대조군 없이 단정하지 않는다.

⚠️ 범위·상태 메모는 음성에서 **문서당 한 번**이면 된다. 언급마다 요구하지 않는다.

## 4. 보고서 형식

```markdown
# <세션> 대본 검수 보고

## 요약
| 문서 | 세그먼트 | R1 | R2 | R3 | R4 | R5 | N | 판정 |
(판정: 재합성 필요 / 재합성 불필요)

## 항목
### <docId> <segId> — R1
- 현재 발화: 「짧은 인용」
- 현재 문서: `파일:줄` 「짧은 인용」
- 왜 문제인가: 한두 문장
- 제안 발화: 그대로 넣을 수 있는 합니다체·음성용 평문 전문(발음사전 표기 사용)
- 근거 URL(있으면):

## 컨트롤러 요청
```

- **맡은 문서 전편, 발화되는 세그먼트 전부**를 읽는다. 표본으로 끝내지 않는다.
- 제안 발화는 컨트롤러가 그대로 적용할 수 있어야 한다.
- 결함이 없는 문서도 요약 표에 적는다.

## 5. 금지

- ⛔ 보고서 외의 파일을 만들거나 고치지 않는다(대본·문서·코드·테스트·발음사전·`audio_meta`).
- ⛔ git 쓰기 명령 금지: 커밋, 브랜치 전환, `stash`, `checkout`, `reset`, push.
- ⛔ `gen_lecture_audio.py`의 `generate`·`enrich`·`verify`·`synthesize`와 `publish_audio.py`를 실행하지 않는다(비용과 파일 변경이 생긴다).
- ⛔ `reviewStatus`·`audioApproved`를 바꾸지 않는다.
- ⛔ 전체 `flutter test`를 돌리지 않는다.
- 모든 파일 명령은 **절대경로**를 쓴다. 맡은 범위 밖 문서로 진행하지 않는다.
- 명세가 부족하면 추측하지 말고 멈춰 `NEEDS_CONTEXT`로 보고한다.

끝나면 보고서 경로와 문서별 판정 건수만 보고하고 정지한다.
