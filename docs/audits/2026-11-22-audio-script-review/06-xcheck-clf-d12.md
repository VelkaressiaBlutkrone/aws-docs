## 측정 방법 메모

- 발화 차이 추출과 `sourceExcerpt` ↔ 학습문서 위치 대조는 스크래치패드의 일회성 스크립트로 했고 레포에는 남기지 않았다.
- `sourceExcerpt`는 대상 세그먼트 전부에서 현재 학습문서의 해당 줄에 실재했다(여러 줄에 걸친 표·목록은 줄 단위로 나눠 확인).
