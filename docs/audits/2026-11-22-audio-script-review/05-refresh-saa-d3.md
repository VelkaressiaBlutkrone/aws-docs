1. 9편 원본을 스크래치패드에 스냅샷한 뒤 `resync`를 **문서당 한 번** 실행했다.

4. 컨트롤러(이 세션)가 직접 검증했다.
   - `resync` 직후 스냅샷과 현재 대본을 맞대어 `id`·`kind`·`skip`·`sourceExcerpt`·`resyncStatus`·`previousSpoken`·`issues`·`scriptText`(전환 문구 제외)·`sourceHash`·`reviewStatus`·세그먼트 순서가 **한 곳도 바뀌지 않았음**을 확인했다(9편 위반 0). skip 세그먼트의 발화도 그대로다. 줄끝은 도구의 `write_json`과 같은 CRLF + 끝 개행이다.
