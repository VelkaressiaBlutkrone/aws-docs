# audio-saa-d4 대본 최신화 결과

- 대상: `saa-t4-1`~`saa-t4-5`의 `script.json` 5개. 브랜치 `feat/audio-script-refresh`, 커밋하지 않았다.
- 이 세션이 쓴 파일은 위 5개와 이 보고서뿐이다. `sourceExcerpt`·`sourceHash`·`id`·`skip`·`reviewStatus`는 손으로 바꾸지 않았다(`resync`가 쓴 값 그대로, `reviewStatus`는 5편 모두 `needs_human_review`).
- `resync`는 문서당 한 번 실행했다. `generate`·`enrich`·`verify`·`synthesize`·`publish_audio.py`는 실행하지 않았고 공식 AWS 문서도 새로 확인하지 않았다. 사실의 기준은 현재 학습문서다.

읽는 법:

- 「직접 쓴 문단」의 문단 수는 `enrichedScriptText`를 쓴 비-제목 세그먼트 수다. `saa-t4-2`~`t4-5`는 `changed`·`new`뿐 아니라 **보존된 문단 전부**를 강의체로 썼다(비-skip 문단 가운데 `enrichedScriptText`가 없는 것은 5편 모두 0개). `saa-t4-1`은 `changed`·`new` 문단과 보고 항목이 걸린 보존 문단(seg040·seg060)만 썼다.
- 제목은 「1) … — …」 꼴의 번호 괄호와 줄표를 「첫 번째, …」로 정리해 `enrichedScriptText`에 넣었다(`scriptText`는 그대로).
- 「쓴 요약」에는 새로 생긴 표·코드뿐 아니라 영문이 남아 gate hard 이던 보존 표의 요약을 다시 쓴 것이 포함된다.
- 보고 항목 수는 `saa-d4.md`의 건수(R1~R5)를 그대로 셌다. `saa-t4-2`~`t4-5`의 R3(절 단위)와 R5(패턴 단위)는 전 문단을 현재 문서에서 다시 써서 닫았다 — 패턴별로 따로 대조한 것이 아니라 재작성으로 흡수했다.
- gate soft는 대부분 「수치 누락: 20%」 꼴이다. 발화가 「20퍼센트」로 읽어 `%` 붙은 토큰이 일치하지 않는 것이고, 수치 자체는 발화에 있다.
- 발화 본문에 남은 영문은 `saa-t4-1 seg006`의 「most cost-effective」 한 곳이다(승인된 음성의 보존 문단이라 두었다). 나머지 4편은 0건이다.

## 컨트롤러 요청

1. **학습문서 의심 — `saa-t4-4.md:127`·`:322`** (고치지 않았다. 발화는 문서대로 말한다)
   - `:127` 표: NAT Gateway 경유 S3 트래픽의 데이터 전송 요금을 「인터넷 아웃바운드 단가 적용」으로 적는다.
   - `:322` 표: 경로를 「EC2 → NAT GW → 인터넷 → S3」, 비용을 「NAT $0.045/GB + 아웃바운드 요금」으로 적는다.
