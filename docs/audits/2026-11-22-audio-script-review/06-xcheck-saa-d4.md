## 문서 쪽 판정

### 「NAT 경유 S3 트래픽에 인터넷 아웃바운드 요금」 — 문서가 틀렸다

대상: `saa-t4-4.md:127` 「| 데이터 전송 요금 | 인터넷 아웃바운드 단가 적용 | S3·DynamoDB는 같은 리전 무료 |」, `saa-t4-4.md:322` 「| EC2(프라이빗) → S3 (NAT 경유) | EC2 → NAT GW → 인터넷 → S3 | NAT $0.045/GB + 아웃바운드 요금 |」

판정: **같은 리전의 S3 로 가는 트래픽은 NAT 를 거쳐도 데이터 전송 요금이 없다.** 붙는 것은 NAT 의 시간 요금과 기가바이트당 처리 요금뿐이다. 경로도 「인터넷」이 아니다. 인터넷 게이트웨이를 지나지만 AWS 네트워크를 벗어나지 않는다. (아웃바운드·리전 간 전송 요금이 붙는 것은 목적지가 인터넷이거나 다른 리전일 때다.)

근거(셋 다 2026-11-22 `curl -sL` 실측 `200 0`):

1. `https://aws.amazon.com/vpc/pricing/` — NAT 게이트웨이 요금 예시(EC2·NAT·S3 버킷이 같은 리전): "There was no charge for the data transfer from the EC2 instance to S3, as it is Data Transfer Out to Amazon EC2 to S3 in the same region."
2. `https://aws.amazon.com/ec2/pricing/on-demand/` — "Data transferred directly (see endpoints) between Amazon S3, … Amazon DynamoDB, … and Amazon EC2 instances in the same AWS Region is free."
3. `https://docs.aws.amazon.com/vpc/latest/privatelink/gateway-endpoints.html` — "While traffic to Amazon S3 or DynamoDB traverses the internet gateway, it does not leave the AWS network."

같은 문서의 다른 자리(`saa-t4-4.md:120` 「NAT Gateway를 경유하면 처리 요금이 발생합니다」)와 문항 쪽 기존 정정(2026-10-28 `saa-t1-3-q9`, 「NAT 경유 S3 트래픽은 AWS 네트워크를 벗어나지 않는다」)은 이미 옳다. 두 표만 남은 것이다.

문서 교체 문장(문서는 이 작업에서 고치지 않았다):

- `saa-t4-4.md:127` → `| 데이터 전송 요금 | 같은 리전 S3·DynamoDB는 없음 (NAT 처리 요금만 붙음) | S3·DynamoDB는 같은 리전 무료 |`
- `saa-t4-4.md:322` → `| EC2(프라이빗) → S3 (NAT 경유) | EC2 → NAT GW → IGW → S3 (AWS 네트워크 안) | NAT 처리 $0.045/GB (같은 리전이면 데이터 전송 요금 없음) |`

이 서술을 그대로 읽는 발화는 두 곳이다(발화가 문서와 일치하므로 X 로 세지 않았다. 문서를 고치면 함께 바꿔야 한다. `saa-t4-4` 의 다른 세그먼트 seg024·seg027·seg054·seg105·seg107 은 「처리 요금」만 말해 영향이 없다).

#### saa-t4-4 seg025 (표, 문서 127줄)
- 현재 발화: 「데이터 전송 요금은 냇 게이트웨이 경유 쪽에 인터넷 아웃바운드 단가가 적용되고, 게이트웨이 엔드포인트 쪽은 에스쓰리와 다이나모디비가 같은 리전이면 무료입니다.」
- 교체 문장: 데이터 전송 요금은 같은 리전의 에스쓰리와 다이나모디비라면 양쪽 모두 없습니다. 냇 게이트웨이를 경유해도 전송 요금이 따로 붙지는 않고, 차이는 기가바이트당 냇 처리 요금에서 납니다.
