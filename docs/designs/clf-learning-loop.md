## Vision

### 10x Check
12개월 이상이 "한국어 AWS 수험생의 기본 시작점"이라면, 10x 버전은 정적 문제은행이 아니라 **학습자를 아는 사이트**다 — 어떤 Task에서 반복해서 틀리는지 기억하고, 다음 모의고사가 그 약점을 겨냥해 출제되는 경험. 이 인프라는 이미 계획 안에 있다: D13(examGuideTaskId) × D14(localStorage 이력)의 결합이 적응형 학습의 데이터 기반이다. 이번 확장 세트는 전부 이 두 결정의 이자 수익.

### 플랫폼 잠재력
Task 매핑 + 응시 이력 = 약점 리포트, 가중 출제, 진행률, (미래) 외부 검증 데이터까지 올라탈 기반 데이터 레이어.

## E-세트 구현 사양 (적대적 리뷰 반영)

> **구현 진척(2026-06-06):** 하위 프로젝트 **#1(기반: 렌더러·퀴즈·이력)** 완료(세션 2, main). **#2 = E3·E4(시험 모드: 타이머·자동제출·세션복원·플래그) 구현 완료**(세션 3, 브랜치 `feat/clf-learning-loop-subproject-2`, 21테스트·web build green). 남은 것: **#3 = E1 오답노트·E2 약점리포트**, **#4 = E5 진행률·E6 가중 모의고사**.

**E1 오답 노트**
- D14 이력 스키마 확장: `{certId, examId, date, correct, total, wrongQuestionIds[], flaggedQuestionIds[], durationSpentSec}` — **이 플랜이 설계 문서 D14의 상위 사양이며, 설계 문서 D14 항목도 동일하게 갱신함**
- stale ID 처리: 오답 노트 로드 시 현재 questionBank에 존재하지 않는 ID는 필터링하고 "개정으로 제외된 문항 N개" 안내 표시

**E2 약점 리포트 / E6 가중 출제 — Task 매핑 없는 자격증 강등 규칙**
- `examGuide` Task 매핑이 있는 자격증(CLF부터)만 Task 단위 리포트·가중 출제 활성
- 매핑 없는 자격증(현 SAA — `SaaRawQuestion`에 도메인 필드 자체가 없음): **전체 점수·회차별 점수 표시로 강등**, Task/도메인 리포트·가중 출제 버튼 비노출(균등 셔플만). SAA 문항의 Task 태깅은 CLF 합격 후 SAA 콘텐츠 작업(해설 업그레이드)에 포함
- E2의 "처방" 정의: Task별 누적 정답률 표 + 정답률 70% 미만 Task에 해당 학습문서 앵커 링크

**E3 타이머 — CEO-D3 결정: 응답+시간 완전 복원** *(주: 설계 문서의 D-번호와 별개 네임스페이스. 설계 문서 D3은 콘텐츠 레지스트리)*
- 시간 출처: `cert.exam.durationMinutes` (CLF-C02 = 90분)
- 응시 세션(시작시각, 현재 응답, 플래그 상태)을 localStorage에 주기 저장(응답 변경 시마다)
- 새로고침/탭 닫기 후 복귀 시 응답·플래그·경과시간 완전 복원. 경과시간은 벽시계 기준(저장된 시작시각 대비)으로 계산 — 새로고침으로 시간 벌기 불가
- 시간 소진 시 자동 제출: 미응답 문항은 오답 처리. 자동제출·수동제출 경합은 제출 가드 플래그로 1회만 실행
- 타이머 인터벌은 재렌더/탭 전환 시 clearInterval (고스트 타이머 방지)

**E4 플래그**
- 응시 중 토글, 상단에 플래그 목록 점프. 제출 전 "플래그 N개 남음" 경고
- 영속성: 응시 세션 저장에 포함(E3 복원 대상). 제출 시 `flaggedQuestionIds`로 이력에 기록되어 오답 노트에서 "플래그했던 문항"도 재검토 가능

**E5 진행률**
- 정의: `문서 진도 = 열람 문서 수 / 현재 문서 총수` (열람 = `<details>` 펼침 이벤트) + `최고 점수`·`마지막 응시일` 별도 표시
- 콘텐츠 증가로 분모가 커져 진행률이 내려갈 수 있음 — 정직하게 표시 (툴팁: "학습 자료가 추가되면 진도율이 변할 수 있습니다")

**멀티탭 동시 응시 (섹션 4 자동 확정 — express)**
- 정책: last-write-wins. 같은 시험 세션 키를 두 탭이 쓰면 마지막 저장이 승리. storage 이벤트 동기화는 구현하지 않음(1인 사용 단계 과잉). 세션 복원 시 "다른 탭에서 진행 중일 수 있음" 안내 없이 단순 복원 — 충돌 시 데이터는 한쪽 탭 기준으로 일관됨

**빈 상태 명세 (섹션 11 자동 확정 — express)**
- 오답 노트: 오답 0건이면 "이 회차는 전부 정답입니다 🎉" + 다른 회차 링크
- 약점 리포트: 이력 0건이면 "모의고사를 풀면 Task별 약점이 여기 표시됩니다"
- 진행률 카드: 기록 0이면 배지 없이 기존 카드 그대로 (빈 0% 표시로 부담 주지 않음)
- 가중 출제: 이력 3회 미만 잠김 메시지 (기존 명세 유지)
- 응시 이력 목록: 0건이면 "첫 응시 기록이 여기 남습니다"

**E6 가중 출제**
- 가중치: Task별 누적 오답률 비례 (최소 가중치 보장으로 전 Task 출제 유지), 이력 3회 미만이면 버튼 비활성 + "응시 기록이 쌓이면 열립니다"
- T3의 시작 게이트(verified < 65 비활성)와 동일 게이트 적용
