G-21은 도메인 1·2 영문 전수 대조로 닫혔고, 그 아래로 학습문서 저작의 **G-22~G-29**, 문항 저작 네 배치의 **G-30~G-60**이 쌓여 있다. ⚠️ **문항 배치에서 가장 값이 큰 것은 G-49다** — 「없다」 규율 3부를 다 해도 **표 구조로 표현된 사실**은 못 잡아서, 참인 문장을 지우지 못하게 하는 **「보존 가드」**를 처음 도입했다) · 깊이 조사 노트 3편(`94` 에이전틱 AI·MCP / `95` 서비스 이름과 정체 / `96` FM 비용·평가·가드레일). ⚠️ **조사 노트는 저작 중에 고쳐진다** — 도메인 3에서 공식 재실측이 `96`의 두 항목을 뒤집어 같은 PR에서 노트를 정정했다(「사용자 지정 모델은 프로비저닝 처리량 없이 못 쓴다」는 과도한 일반화 · 「작업 완료율은 근거가 없다」는 검색 범위 문제). **노트를 고치지 않으면 다음 배치가 같은 오류를 다시 쓴다.**

⚠️ **이 트랙에서 처음 드러난 것: 레포 `exam_guides/*.json`을 믿고 저작하면 안 된다.** AIF-C01.json(2026-06-11 수집)은 목표 69건 중 **17건이 공식 v1.1 본문과 다르고**, 그중 9건은 서비스·지표 목록이 실제로 달라 **공식 범위에 없는 서비스 4개**(`AWS Audit Manager` · `Amazon A2I` · `SageMaker Model Monitor` · `Amazon Q`)를 예시로 들고 있다. 다른 5종 JSON도 같은 시기 수집분이므로 **각 자격증 착수 시 같은 기계 대조를 먼저 돌린다**(스크립트 패턴은 `97-repo-json-diff.md` §1).
