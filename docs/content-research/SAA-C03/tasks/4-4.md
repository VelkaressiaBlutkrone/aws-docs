### 2-1. 데이터 전송 요금의 경계 (Knowledge 5·6, Skill 3)
| 경계 | 과금 | 근거 |
|---|---|---|
| **인터넷 → AWS(인바운드)** | 무료("Data ingress to AWS is free") | F-03 |
| **같은 AZ** (프라이빗 IP) | 무료 | F-02 |
| **AZ ↔ AZ** (같은 리전) | **양방향 각각 과금**(EKS 가이드 서술 $0.01/GB 각 방향; CUR에는 리소스마다 `DataTransfer-Regional-Bytes` 인/아웃 두 줄) | F-01, F-02 |
| **리전 ↔ 리전** | 송신 리전의 리전 간 전송 요금(수신은 무료; TGW 리전 간 예시 $0.02/GB) | F-12 |
| **AWS → 인터넷(DTO)** | 월 100 GB 무료(전 서비스·리전 합산), 이후 계층 요금(EC2·S3·RDS 등 집계) | F-03 |
| **CloudFront 경유** | AWS 오리진→CloudFront 무료, 월 1 TB DTO 무료 | F-17 |

### 2-2. NAT 게이트웨이 — 구성 유형과 비용 (Knowledge 4, Skill 1)
- **과금**: NAT Gateway-시간(부분 시간도 1시간) + **처리 GB당(출발지·목적지 무관, S3로 가는 트래픽도 포함)** + 표준 전송 요금. 예시(US East 오하이오) $0.045/시간·$0.045/GB. 같은 AZ의 EC2↔NAT(프라이빗 IP) 전송은 무료, **다른 AZ면 AZ 간 전송 요금이 추가** (F-04).
- **단일 공유 NAT vs AZ별 NAT**: 한 NAT는 하나의 AZ에서만 동작 → 그 AZ 장애 시 연결이 끊기고, 다른 AZ 리소스는 교차 AZ 전송 요금을 낸다. AWS 권고: **AZ마다 NAT Gateway 1개 + AZ 내 라우팅**(가용성+교차 AZ 요금 회피), 비용은 *시간당 요금이 AZ 수만큼* 늘지만 같은 트래픽의 처리 요금은 NAT 수와 무관 (F-05, F-06). 소규모·비프로덕션에서 단일 NAT로 시간 요금을 줄이는 것은 가용성과 교환하는 *설계 판단*(공식 권고는 AZ별 NAT).
- **NAT Gateway vs NAT instance**: 게이트웨이=AWS 관리·AZ 내 이중화·100 Gbps까지·크기 선택 불필요·과금(개수·시간·처리량) / 인스턴스=장애 조치 스크립트·인스턴스 유형 대역폭·직접 패치·과금(인스턴스 수·시간·유형) — AWS는 게이트웨이 권장 (F-06). 비용 항목의 구성만 공식 비교에 있고(게이트웨이=개수·시간·처리량, 인스턴스=개수·시간·인스턴스 유형/크기) 트래픽 규모별 손익분기 수치는 확보하지 못함(`99-gaps.md`).
- **Regional NAT gateway**: ENI가 생긴 AZ로 자동 확장·축소(최대 60분), 자동/수동 모드, Private NAT 미지원 — 요금 구조는 이번 조회에서 미확인 (F-07, `1-2.md` F-10).
- **공용 IPv4**: NAT 게이트웨이의 EIP도 시간당 과금. "퍼블릭 서브넷 인스턴스를 프라이빗+NAT로 옮길지"는 `(NAT 시간+NAT IP+처리비)/기존 공용 IP 비용` 비율로 판단 (F-08).
- **절감 4단계**: ① 리소스와 NAT를 같은 AZ에(또는 AZ별 NAT) ② S3·DynamoDB는 Gateway 엔드포인트 ③ 그 외 AWS 서비스는 Interface 엔드포인트(트래픽이 많을 때) ④ 유휴 NAT 정리(Compute Optimizer 유휴 권고) (F-05, F-21).

### 2-3. VPC 엔드포인트 비용 (Skill 3)
| 유형 | 요금 | 제약 |
|---|---|---|
| **Gateway**(S3·DynamoDB) | 시간·전송 요금 **없음** | VPC 경계 확장 불가(피어링·VPN·DX 경유 불가), 라우트 테이블 항목 |
| **Interface**(PrivateLink) | **AZ별 시간당**(pending 상태도 과금) + 처리 GB당(리전 합계 계층: 첫 1 PB $0.01 → 다음 4 PB $0.006 → 5 PB 초과 $0.004) | 처리 요금은 출발·목적지 무관, 엔드포인트 간 AZ 전송은 별도 과금 없음(EKS 가이드) |
- 선택: **동일 리전 S3·DynamoDB=Gateway(무료)**, 타 리전 S3 접근이나 온프레미스에서의 접근처럼 Gateway가 안 되는 경우와 그 외 서비스=Interface. NAT 트래픽의 대부분이 엔드포인트 지원 서비스면 Interface로 NAT 처리비(≈GB당 $0.045)를 엔드포인트 처리비(≈GB당 $0.01)로 대체 (F-05, F-10).

### 2-4. VPC 피어링 vs Transit Gateway vs PrivateLink (Knowledge 6, Skill 3)
| 항목 | VPC 피어링 | Transit Gateway | PrivateLink |
|---|---|---|---|
| 고정 요금 | 없음 | **첨부당 시간 요금**(US East 오하이오 $0.05/첨부·시간 예시) | 엔드포인트 AZ별 시간 |
| 처리 요금 | 없음(전송 요금만) | **$0.02/GB**(송신 VPC 소유자에게) | GB당(계층) |
| AZ 간 | **같은 AZ 무료, AZ 교차 과금** | **TGW 경유 AZ 간 추가 전송 요금 없음**(처리 요금만) | 별도 AZ 전송 요금 없음 |
| 전이 라우팅 | 불가(1:1) | 가능(허브) | 서비스 단위 노출 |
| 적합 | 소수 VPC·대용량 트래픽 | 다수 VPC·온프레미스 허브 | 서비스 소비자/제공자 모델(서비스 단위 노출·AWS 서비스 비공개 접근) |
- **판단**: VPC가 소수이고 트래픽이 많으면 *피어링이 가장 쌈*(고정·처리 요금 없음), VPC 수가 많거나 전이 라우팅·온프레미스 통합이 필요하면 TGW(운영 복잡도 감소, 처리 요금 감수). 리전 간 TGW 피어링은 첫 TGW에서 처리비 + 리전 간 전송($0.02+$0.02) (F-11, F-12). 연결 수 산식 N(N−1)/2와 비전이·CIDR 중복 불가는 `3-4.md` F-11.

### 2-5. 네트워크 연결 선택 — 인터넷 vs VPN vs Direct Connect (Knowledge 5, Skill 2)
| 항목 | 인터넷 | Site-to-Site VPN | Direct Connect |
|---|---|---|---|
| 고정 비용 | 없음 | **연결-시간당**(5 Gbps 연결·VPN Concentrator는 별도 요율) | **포트-시간당**(+크로스 커넥트·사업자·장비) |
| 데이터 전송(AWS→외부) | 인터넷 DTO 요율 | **인터넷 DTO 요율**(EC2 요금표) | **낮은 DX DTO 요율**(위치·리전별) |
| 인바운드 | 무료 | 무료 | **무료** |
| 대역폭 | 가변 | 터널당 1.25 Gbps(대용량 5 Gbps) | 전용 1/10/100/400 Gbps·호스팅 50 Mbps~25 Gbps |
| 특징 | 가장 단순 | 암호화 터널(연결당 2개, `3-4.md` F-19), 인터넷 경유 | 전용 연결(속도 `3-4.md` F-18), 지속·대용량; 구축 리드타임·일관 지연의 공식 문장은 미확보(`99-gaps.md`) |
- **손익분기**: DX는 포트 시간 고정비가 있으므로 *지속적 대용량 아웃바운드*일 때만 인터넷보다 저렴(예시: 시드니 인터넷 $0.114/GB vs DX $0.042/GB; 미국 DX DTO 예시 $0.02/GB). 일시적·소량이면 VPN/인터넷, DX 백업은 VPN(단 1 Gbps 초과 DX에는 비권장) (F-13, F-15). 총비용은 AWS 요금 외 ISP·크로스 커넥트·랙·장비까지 포함 (F-13).
- **가속 VPN**: 연결 요금 + Global Accelerator 2개의 시간 요금 + DT-Premium → 가장 비쌈, 글로벌 지점 성능용 (F-14).

### 2-6. 대역폭 할당 — 단일 VPN vs 복수 VPN, DX 속도 (Skill 7)
- **VPN**: 표준 터널 최대 1.25 Gbps(140,000 pps)·대용량 터널 5 Gbps·Concentrator 터널 100 Mbps. 더 큰 처리량은 **Transit Gateway + 동적(BGP) 라우팅 + ECMP**로 여러 터널 집계(최대 약 50 Gbps), **VGW는 다중 터널 ECMP 미지원**, 정적 라우팅은 ECMP 불가 (F-15, `3-4.md` F-19).
- **Direct Connect**: 포트 속도는 고정 시간 요금과 직결 — 과대 프로비저닝이면 낭비, 부족하면 병목 → 사용량과 성장률로 선택. 호스팅 연결(50 Mbps~25 Gbps)로 작게 시작할 수 있고, 네트워크 서비스 사업자를 쓰면 대역폭 약정을 바꿀 수 있는지·시간은 **사업자 계약에 달림** (F-13, `3-4.md` F-18).
- **TGW 한도**: VPC 첨부 AZ당 100 Gbps (F-15).

### 2-7. CDN·엣지 캐싱의 전략적 필요 (Skill 4)
- **비용 효과**: AWS 오리진→CloudFront 무료 + 월 1 TB 무료 DTO + 계층 요금 + 캐시 히트 시 오리진 요청 감소. 콘텐츠가 *캐시 가능*하고 사용자가 분산·다수일 때 의미 (F-17).
- **절감 수단**: **가격 클래스**(사용자 위치에 맞춰 100/200/All — 성능이 중요하면 All), Security Savings Bundle(최대 30%+WAF 크레딧), **flat-rate 요금제**(Free/Pro/Business/Premium; WAF·DDoS·봇 관리·Route 53 DNS·CloudWatch Logs·TLS·서버리스 엣지 컴퓨트·S3 크레딧 포함, **초과 요금 없음**), 요청 수·Origin Shield 요청 요금 고려 (F-17).
- **Global Accelerator는 CDN이 아니다**: 캐싱 없음, 가속기당 시간 고정 요금 + DT-Premium → *성능·고정 IP·빠른 장애 조치* 목적이지 비용 절감 수단이 아님 (F-16, `3-4.md` F-06).

### 2-8. 로드 밸런싱·DNS 비용 (Knowledge 3·7)
- **ALB**: 시간+LCU(최대 차원 하나) — 호스트·경로 라우팅으로 통합해 LB·공용 IPv4 수를 줄임 (`4-2.md` F-17·F-18). ELB 사용 시 인스턴스의 공용 IP 자동 할당을 끌 수 있음 (F-08). 교차 영역 LB의 AZ 간 전송은 `2-1.md` F-25.
- **Route 53**: 호스티드 영역 월 $0.50(25개까지)·퍼블릭 쿼리 $0.40/백만, **Alias A/AAAA가 AWS 리소스(ELB·CloudFront·API Gateway·VPC 엔드포인트·S3 웹사이트·Global Accelerator 등)를 가리키면 쿼리 무료**, **프라이빗 호스티드 영역 쿼리 무료**; 지연 기반 쿼리는 더 비쌈 (F-18).
- **Resolver 엔드포인트**: ENI(IP)당 시간 요금 + 쿼리 요금 → IP 2개 기준 월 약 $182.50부터. 절감=규칙·아웃바운드 엔드포인트 **공유**, **TTL 상향**, 프라이빗 호스티드 영역을 여러 VPC에 연결 (F-19).

## 3. 시험에서 묻는 방식 (패턴)
1. **프라이빗 서브넷의 S3 대용량 업로드, 비용 절감**: → **S3 Gateway 엔드포인트**(무료, NAT 처리비 제거). 함정: Interface 엔드포인트·NAT 증설.
2. **NAT 비용 (다중 AZ)**: "AZ-B 인스턴스가 AZ-A의 NAT 사용" → **AZ별 NAT** 또는 같은 AZ 정렬(교차 AZ 전송 제거, HA).
3. **VPC 연결 비용**: "VPC 3개·대용량" → **피어링**; "수십 VPC·전이 라우팅·온프레미스" → **Transit Gateway**.
4. **온프레미스 대용량 지속 전송(→AWS 외부)**: → **Direct Connect**(DTO 저렴); 임시·소량 → VPN; DX 백업 → VPN.
5. **글로벌 정적 콘텐츠**: → **CloudFront**(오리진 전송 무료, 가격 클래스로 비용 조정).
6. **고정 IP·TCP/UDP 지연**: → **Global Accelerator**(고정 시간+DT-Premium, *비용 절감 목적 아님*).
7. **DNS 비용**: "AWS 리소스를 가리키는 레코드" → **Alias**(쿼리 무료); "VPC 내부 이름" → 프라이빗 호스티드 영역(쿼리 무료).
8. **VPN 대역폭 한계**: "단일 VPN 터널 1.25 Gbps 부족" → **TGW + ECMP 다중 터널**.
9. **스로틀링**: "특정 IP의 과도한 요청으로 비용 급증" → **WAF rate-based rule**; "클라이언트별 API 호출 제한" → **API Gateway 사용량 계획**.
10. **공용 IPv4 비용**: → ELB 뒤로 이동·IPv6·Instance Connect Endpoint.
11. **교차 AZ 전송 비용 큼**: → 같은 AZ 정렬/토폴로지 인식 라우팅(HA 요건 확인).
12. **기존 환경 비용 점검**: → Cost Explorer/CUR 사용 유형 분석, NAT 지표, Compute Optimizer 유휴 NAT.

## 4. 흔한 함정·혼동 짝
- **TGW 경유 AZ 간 트래픽에 AZ 전송 요금이 또 붙는다?** 아니다 — TGW 처리 요금($0.02/GB)만(피어링은 AZ 교차 시 전송 요금). "TGW는 $0.03/GB(교차 AZ+처리)"라는 계산은 근거 없음.
- **Gateway 엔드포인트는 온프레미스·피어링·타 리전에서 쓸 수 없다**: VPC 경계 확장 불가.
- **Interface 엔드포인트는 pending 상태에도 시간 과금**, AZ마다 별도.
- **NAT Gateway 처리 요금은 목적지를 가리지 않는다**: S3로 가도 부과 → 엔드포인트로 우회.
- **NAT 개수를 늘려도 처리 요금 총합은 같다**(트래픽 불변) — 늘어나는 건 시간 요금(AZ 수만큼).
- **단일 NAT는 가용성 SPOF + 교차 AZ 비용**: 비용만 보고 줄이면 장애 시 연결 끊김.
- **공용 IPv4는 "사용 중이어도" 시간당 과금**(2024-02-01~): EIP를 붙여 두면 무료라는 옛 상식은 틀림.
- **Direct Connect ≠ 전송 무료**: 포트 시간+DTO(인바운드만 무료). 저트래픽이면 인터넷/VPN이 쌀 수 있음.
- **VPN 연결 요금 + 인터넷 DTO 요율**: VPN은 전송 요율이 인터넷과 같다(DX만 낮은 요율).
- **VGW는 ECMP 불가, TGW는 가능(동적 라우팅 필요)**.
- **Global Accelerator는 캐싱·비용 절감 서비스가 아님**(CloudFront와 혼동). 가속 VPN은 GA 요금이 가산됨.
- **CloudFront 비용 절감은 캐시 가능 콘텐츠 비중에 비례**; 가격 클래스를 낮추면 일부 지역 지연 증가.
- **Route 53 Alias 무료는 지정 AWS 서비스 대상만**; 일반 도메인 CNAME 쿼리는 과금.
- **Resolver 엔드포인트는 IP(ENI)마다 시간 과금** — 불필요한 엔드포인트·IP 정리, 규칙 공유.
- **스로틀링 ≠ 오토스케일**: 한도를 올리면 백엔드·비용도 늘어남(테스트한 값까지만).

## 6. 자가 점검 문항 후보 (재료)
1. **NAT 비용**: 프라이빗 서브넷 EC2가 매일 수백 GB를 S3에 업로드한다. → **S3 Gateway 엔드포인트**(시간·전송 요금 없음, NAT 처리 요금 제거). 오답: Interface 엔드포인트, NAT 추가. 근거 F-05·F-10.
2. **다중 AZ NAT**: 인스턴스 대부분이 AZ-B인데 NAT가 AZ-A에만 있다. → **AZ-B에 NAT 추가**(교차 AZ 전송 제거·가용성), NAT 시간 요금은 AZ 수만큼 증가, 처리 요금 총합은 불변. 근거 F-05·F-06.
3. **NAT instance vs gateway**: 대역폭·가용성·관리 차이는? → 게이트웨이=AWS 관리·AZ 내 이중화·최대 100 Gbps, 인스턴스=직접 관리·인스턴스 유형 대역폭·장애 조치 스크립트. AWS 권장=게이트웨이. 근거 F-06.
4. **VPC 연결 비용**: 한 리전 VPC 4개, 서로 대용량 통신. → **VPC 피어링 풀메시**(연결 6개, 고정·처리 요금 없음, 같은 AZ 무료). VPC가 수십 개·전이 필요→TGW(첨부 시간+$0.02/GB). 근거 F-11·F-12.
5. **TGW AZ 간**: 서로 다른 AZ의 VPC가 TGW로 통신한다. 비용은? → **TGW 처리 요금만**(AZ 간 목적지 전송 요금 없음). 근거 F-12.
6. **DX vs 인터넷**: 월 400 TB를 온프레미스로 보낸다. → **Direct Connect**(DTO 낮은 요율, 포트 시간 고정비, 인바운드 무료; 손익분기 계산). 소량·일시적이면 VPN/인터넷. 근거 F-13.
7. **VPN 대역폭**: 단일 터널로 3 Gbps가 필요하다. → **TGW + 동적 라우팅 + ECMP 다중 터널**(터널당 1.25 Gbps). VGW는 ECMP 불가. 근거 F-15.
8. **CloudFront 비용**: 글로벌 정적 파일을 S3에서 직접 서빙 중. → **CloudFront**(S3→CloudFront 무료, 월 1 TB DTO 무료, 가격 클래스로 지역 조정). 근거 F-17.
9. **고정 IP**: 정적 IP와 지연 단축이 필요하나 비용 절감도 원한다. → Global Accelerator는 **고정 시간+DT-Premium로 추가 비용**(절감 수단 아님) — 비용 절감이 목표면 CloudFront/Alias 중심. 근거 F-16.
10. **DNS 비용**: ALB를 가리키는 레코드 쿼리 비용? → **Alias A/AAAA는 무료**, 프라이빗 호스티드 영역 쿼리 무료. 근거 F-18.
11. **공용 IPv4**: 퍼블릭 서브넷의 EC2 100대가 각자 EIP를 쓴다. → 공용 IPv4는 시간당 과금 → **ELB 뒤로 이동·자동 할당 해제·IPv6**, NAT 이전은 비용식 검토. 근거 F-08.
12. **스로틀링**: 한 IP가 API를 과도하게 호출해 비용이 급증. → **WAF rate-based rule**(또는 API Gateway 사용량 계획). 근거 F-20.
13. **Resolver 비용**: 온프레미스 DNS 전달용 엔드포인트를 계정마다 만들었다. → **Resolver 규칙·아웃바운드 엔드포인트 공유**(IP당 시간 과금). 근거 F-19.
