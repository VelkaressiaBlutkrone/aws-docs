## 1. 현재 상태 실측 (2026-11-18)

### 1-1. 플랫폼

- `flutter_app/` 에 **`android/`·`ios/` 디렉터리가 없다** — 웹 전용 빌드다.
- `lib/firebase_options.dart` 는 `web` 만 구성돼 있고 `android`·`ios` 는 **「not been configured」 예외를 던진다.**
- 로그인은 `firebase_auth_service.dart:23` 의 `signInWithPopup(GoogleAuthProvider())` — **웹 팝업 전용**이라 Android 에서는 다른 흐름이 필요하다.

### 1-2. 웹 전용 코드 네 곳 (조건부 import, 비웹은 스텁)

| 파일 | 웹 구현 | 비웹 스텁의 동작 | Android 에서의 결과 |
|---|---|---|---|
| `lib/data/local_kv.dart` | `localStorage` | `defaultBackend()` 가 **`MemoryBackend`** | ⚠️⚠️ **학습 기록·시험 세션·일정이 앱 재시작마다 사라진다** |
| `lib/data/audio_runtime.dart` | DOM `<audio>` + Media Session | `audioRuntime == null` | 오디오 강의 미동작(「오디오는 웹에서만 재생할 수 있습니다」) |
| `lib/data/cloud/app_resume.dart` | 가시성 이벤트 | 빈 스트림 | 앱 복귀 시 동기화 재개 신호 없음 |
| `lib/util/open_link.dart` | `window.open` | no-op | 출처·외부 링크가 열리지 않음 |

### 1-3. 콘텐츠 배포

- 학습문서·문항·시험 가이드는 **`rootBundle` 자산**이다(`lib` 의 `rootBundle.loadString` 9곳). 앱에서도 읽히지만 **문항 하나를 고치려면 스토어 업데이트와 심사**를 거친다.
- 오디오만 R2(`aws-audio.leva.ai.kr`)에서 내려받는다.
- 이 레포는 콘텐츠 정정이 잦다(PR 번호가 2026-11-08 #403 → 2026-11-18 #609, 그 대부분이 콘텐츠·가드 정정이다). **출시 전에 원격 배포 여부를 결정**해야 하고, 출시 후에는 바꾸기 어렵다.

- ⚠️ 웹 빌드는 그대로 유지한다(GitHub Pages 라이브). Android 작업이 웹 회귀를 만들지 않는지 기존 4,201 테스트 + 라이브 확인으로 본다.

## 4. 추가 기능 설계 방향 (상세 설계는 착수 시 별도 문서)

### 4-1. 공지 · 피드백 게시판

| 구성 | 연내 | 이유 |
|---|---|---|
| 운영자 공지(목록·상세·새 공지 표시) | ✅ | 사용자 생성 콘텐츠가 아니다 |
| 사용자 → 운영자 피드백(문항 오류 신고 포함) | ✅ | 다른 사용자에게 보이지 않아 UGC 공개 요건이 거의 없다 |
| 사용자 간 커뮤니티(글·댓글) | ❌ 출시 후 | 약관 동의 · 신고 · 지속 모더레이션 운영 부담(§2) |

- 저장소는 기존 Firestore 를 쓰고 **보안 규칙**을 함께 쓴다(공지는 운영자만 쓰기, 피드백은 본인만 쓰기·운영자만 읽기). 규칙 테스트는 `tool/firestore_rules_test` 에 더한다.
- ⭐ **문항 오류 신고**를 피드백의 한 유형으로 두면 지금의 외부 검수 흐름(보고 → 실측 → 가드)에 사용자 신고가 들어온다.

### 4-2. 프레젠테이션 학습 화면

- **재료는 이미 있다** — 오디오 대본 `script.json` 이 학습문서를 구간(세그먼트)으로 나누고 각 구간의 원문 발췌·발화문을 담는다. 「구간 하나 = 슬라이드 한 장 + 그 구간 음성」으로 묶는다.
- ⚠️ **텍스트 출처를 먼저 정한다** — 대본 43편 중 `sourceHash` 가 현재 md 와 맞는 것은 **1편**뿐이다(2026-11-17 실측). 슬라이드를 대본 발췌로 만들면 **현재 학습문서와 다른 문장**이 나온다. 후보: ① 현재 md 를 구간 규칙으로 직접 나눠 슬라이드를 만들고 음성은 「대응하는 경우만」 잇기 ② 재합성으로 대본을 md 에 맞춘 문서만 프레젠테이션 제공.
- 오디오가 없는 자격증(현재 CLF·SAA 외)은 **텍스트 전용 슬라이드**로 시작할 수 있다.
- 디자인은 `DESIGN.md` 규칙(반마케팅 에디토리얼, 액센트 틸)을 따른다.
