# CLF 오디오 학습 페이지 청취·동작 점검 가이드 (라이브 dogfood)

자격증별 오디오 학습 페이지(허브 → cert 페이지 + 하단 트랜스포트 + 통합 플레이리스트) 기능을 **라이브 사이트에서 직접 듣고 눌러 보며** 검증하는 체크리스트. Claude는 mp3를 들을 수 없어 **이 청취·인터랙션 점검은 사람(검수자)만** 수행한다.

> 이 문서는 **기능 동작** 점검이다. 음성 **콘텐츠**(약어 발음·표 요약 정확성·볼륨)의 검수·승인은 `docs/audio-content-review-guide.md`를 따른다.

관련: 설계 `docs/superpowers/specs/2026-06-27-cert-audio-page-design.md`, 콘텐츠 검수 `docs/audio-content-review-guide.md`.

---

## 0. 진입 경로

- **사이트**: 배포된 GitHub Pages 주소(해시 라우팅 `#/...`).
- **상단 메뉴 "오디오"**: `audioLectureEnabled`(프로덕션 on) + 승인 오디오 ≥1일 때만 노출. 현재 승인 오디오는 **CLF-C02(19문서)뿐**이라 CLF에서만 보인다. 좁은 화면(<768px)에선 햄버거 메뉴 안에 들어 있다.
- **경로**: 상단 "오디오" → 허브 `#/audio` → 자격증 카드(현재 CLF 1개) → `#/cert/CLF-C02/audio`.
- **직접 URL로도 진입 가능**: `…/#/audio`, `…/#/cert/CLF-C02/audio`.

## 1. 오디오 허브 (`/audio`)

| # | 점검 항목 | 기대 |
|---|---|---|
| 1-1 | 카드 제목 | 자격증 **표시명**(`AWS Certified Cloud Practitioner`)이 제목으로 보인다(코드만이 아니라). |
| 1-2 | 카드 보조줄 | `CLF-C02 · 강의 19개`처럼 코드·강의 개수가 보인다. |
| 1-3 | 카드 탭 | 자격증 오디오 페이지(`/cert/CLF-C02/audio`)로 이동한다. |

## 2. 자격증 오디오 페이지 (`/cert/CLF-C02/audio`)

### 2-A. 화면 구성
| # | 점검 항목 | 기대 |
|---|---|---|
| 2-1 | 헤더 | `‹ CLF-C02 / 오디오 강의` (뒤로 가능). |
| 2-2 | 트랙 목록 | 19개 강의가 번호·제목과 함께 순서대로. 각 행에 "문서 보기" 링크. |
| 2-3 | 하단 트랜스포트 | 좌→우 **처음 · 이전 · 재생/정지 · 다음 · 마지막** + 현재 트랙 제목·상태 텍스트. |

### 2-B. 재생·트랜스포트
| # | 조작 | 기대 |
|---|---|---|
| 2-4 | 트랙 행 본문 탭 | 그 트랙이 재생된다. 현재 트랙이 목록에서 **강조(accent)** 표시. |
| 2-5 | 재생/정지(가운데 원형) | 토글된다. 상태줄: "재생 중입니다." ↔ "일시정지했습니다." |
| 2-6 | 다음 / 이전 | 다음 / 이전 트랙으로 넘어가 바로 재생. |
| 2-7 | 처음 / 마지막 | 첫 / 끝 트랙으로 점프해 재생. |
| 2-8 | **경계 muted** | 첫 트랙에선 **처음·이전** 버튼이 흐리게(muted) + 눌러도 무반응. 마지막 트랙에선 **다음·마지막**이 동일. |
| 2-9 | **수동 전환(자동전환 없음)** | 한 트랙을 **끝까지** 재생하면 멈추고 "재생을 마쳤습니다. 다음 강의를 들어 보세요." 표시. **자동으로 다음 트랙으로 넘어가지 않는다.** 다음 버튼을 눌러야 이어진다. |
| 2-10 | **같은 트랙 재선택** | 재생 중인 트랙의 행을 다시 탭해도 **처음부터 재시작하지 않는다**(그대로 재생 유지). 일시정지 상태였다면 **이어재생**된다. |

### 2-C. 연속성 ("주머니 라디오")
| # | 조작 | 기대 |
|---|---|---|
| 2-11 | 재생 중 "문서 보기" | 해당 학습문서로 이동하되 **재생이 끊기지 않는다.** 학습문서 하단 미니플레이어가 **현재 재생 중인 트랙**을 반영. |
| 2-12 | 문서 → 뒤로 → 오디오 페이지 재진입 | 재생·현재 위치가 그대로 유지. |
| 2-13 | 학습문서 **직접** 진입(아무 것도 재생 안 한 상태) | 그 문서 오디오가 미니플레이어에 **준비(idle)**된다(재생 버튼 누르면 그 문서부터). |

## 3. 비목표 — "안 되는 게 정상"

다음은 **의도적으로 빼둔** 기능이다. 없다고 버그로 보지 말 것:

- 자동(연속) 재생 — 트랙이 끝나도 다음으로 자동 진행 안 함(2-9).
- 재생 속도 조절 · 탐색바(seek) · 진행률 바 · 다운로드.
- 다중 자격증 정렬/필터(현재 오디오 보유 자격증이 CLF 하나).
- 잠금화면 트랜스포트 버튼 확장 · 오디오 진행 이력 저장.

---

## 4. 플랫폼·함정

- **웹 전용**(DOM `<audio>`). 데스크톱·모바일 브라우저에서 동작.
- **iOS**: 재생은 사용자 탭에서 시작해야 한다(브라우저 자동재생 차단). **잠금화면 연속재생·인터럽션 후 재개·백그라운드 재생**은 이 dogfood 범위가 아니라 **iOS 실기기 수동 게이트(M1 T6)** 로 별도 검증한다.
- 첫 재생 시 "오디오를 준비하고 있습니다…"가 잠깐 보일 수 있다(버퍼링). 실패 시 "오디오를 재생하지 못했습니다."
- 음질(볼륨·약어 발음·표 요약)은 콘텐츠 영역 — `docs/audio-content-review-guide.md`로 점검.

---

## 5. 문제를 찾으면

1. **무엇이**(어느 트랙·어느 버튼·어느 화면) **어떻게** 어긋났는지.
2. **재현 절차**(클릭 순서)와 **브라우저·기기**(예: Chrome 데스크톱, iOS Safari).
3. 콘텐츠(발음·요약) 문제면 `docs/audio-content-review-guide.md`의 수정 절차(SUMMARIES/lexicon)로, 동작(UI·재생 흐름) 문제면 설계 정본(`docs/superpowers/specs/2026-06-27-cert-audio-page-design.md`)과 대조해 보고.
