# 자격증 수명 안내 설계 (2026-11-22)

## 의도

앱이 응시가 끝났거나 곧 끝나는 시험을 현행 시험처럼 보여 준다. 학습자가 이미 없는 시험을 준비하지 않도록, 시험 코드 옆과 상세 화면에서 상태를 바로 알린다.

- **목표:** `SAP-C02`·`DVA-C02`·`ANS-C01`·`MLA-C01` 의 수명 안내와 공식 출처 링크.
- **비목표:** `SAP-C03`·`MLA-C02` 콘텐츠 전환, 시험 코드·주소 변경, DVA 12월 전환.
- **실패로 볼 것:** 공식이 확정하지 않은 날짜를 확정처럼 적는 것. 마지막 응시일 당일을 종료로 표시하는 것.

## 설계

- `lib/data/cert_lifecycle.dart` 가 수명 데이터의 단일 출처이고, 코드와 오늘 날짜로 배지·문구·출처를 계산한다.
- 마지막 응시일 **당일까지는 응시 가능**이고 다음 날부터 종료로 바뀐다.
- `MLA-C01` 의 날짜는 **예정**이라 날짜가 지나도 「종료」로 단정하지 않고 공식 확인을 안내한다.
- 표시 위치: 홈 단계별 카드와 콘텐츠 카드의 배지, 상세 헤더의 안내 + 공식 링크, `web/index.html` 의 noscript 목록.
- 색은 DESIGN.md 의 `warningWeak` 배경 + `warningText` 글자다. 빨강은 쓰지 않는다.
