## 문제 정의

현재 `parse_segments`의 `scriptText = _clean_inline(원문 줄)` 이다 — 학습문서 마크다운을 기호만 벗기고 발음사전 치환한 **1:1 전사**. 단어·구조·순서가 학습문서 그대로다. 실측 증거(clf-t1-1):

- **seg001**: `"커버하는 공식 Task — 씨엘에프 씨 공이 · 도메인 1 「클라우드 개념」(24%) · Task 1.1 … (clf-t1-1) 이 문서는 위 한 Task에 1:1로 매핑됩니다."` → **메타 스캐폴딩**(Task 매핑·문서 ID·퍼센트)을 소리내어 읽는다.
- **seg004**: 학습목표 **체크리스트 불릿**을 "~할 수 있다 ~할 수 있다" 나열로 낭독.

사용자 표현: "실제 강사가 수업에 학생들을 앉혀놓고 책만 읽는 강사는 없다." 문제는 두 겹이다:
1. **애초에 말하면 안 되는 것을 읽음**(스캐폴딩·체크리스트 문법·문서 ID) — 결정적이고 싼 문제.
2. **진짜 내용조차 '읽기용' 문장**이라 귀로 듣기엔 호흡·연결·강조·예시가 없음 — 재저작이라 비싸고 위험.

## 무엇이 좋아지나 (delight)

학습자가 출퇴근·이동 중 "듣기만 해도 이해되는" 강의를 얻는다. seg001 같은 "씨엘에프 씨 공이 (clf-t1-1)" 낭독이 사라지고, 도입 훅("자, 클라우드가 왜 게임을 바꿨는지부터 보겠습니다")·연결·예시가 붙어 텍스트를 눈으로 안 봐도 흐름이 잡힌다.

## 제약

- **환각가드(④)의 실제 동작**(코드 확인, L313-329·L496-503): `check_token_preservation(source, target)`은 **세그먼트별로 원문 핵심 토큰(약어=hard, 수치=soft)이 대본에 보존됐는지만** 검사한다. **추가된 말은 막지 않는다.** 즉 "사실 누락" 검사지 "원문에 없는 말 추가" 검사가 아니다.
- 따라서 자동 가드는 A도 B도 막지 않는다. B가 비유·예시를 더해도 **각 세그먼트가 원문 약어·수치만 유지하면 통과**한다. B의 진짜 위험은 자동으로 못 잡는 **사실 환각**(틀린 예시·잘못된 설명)이며, 이는 **사람 검수만** 잡는다.
- 스캐폴딩 낭독은 이미 있는 `skip` 플래그로 안 읽으면 보존 이슈도 없다(표가 `audioSummary` 쓰는 패턴과 동일).
- 학습문서(verified)가 정본, 대본은 파생물. `generate`가 수동 산출물을 덮어쓰는 기존 함정([[content-review-pipeline-planned]])처럼 재저작 산출물도 덮어쓰기 안전장치 필요.
- 재합성은 audio_meta reviewStatus를 리셋 → 재승인 flip 필요([[audio-section-timestamps-shipped]]). Polly 19문서 재합성 ≈ $1.3(소액). **단, 재합성엔 ffprobe(chapters 실측)+ffmpeg(loudnorm) 설치 환경 필수**(`_audio_duration_ms` 없으면 RuntimeError, loudnorm 없으면 sys.exit) — 착수 전 환경 확인.
- 앱(Dart)은 무변경 목표. **앵커 헤딩 경계는 불변**이므로 chapters 스키마·재생 인프라는 영향 없으나, 스캐폴딩 skip·도입문 가산으로 **섹션 길이가 바뀌어 fraction 값은 재계산된다(정상 — 시크포인트 미세 이동, 무해)**.
- **삽입 텍스트(도입·전환·마무리)도 gate의 평문 hard 규칙을 통과해야 한다**: 기호 `→ ≠ ↓ § |`·URL·`](` 링크 금지(L480-492). 토큰 보존만으론 불충분 — 순수 평문 네비게이션 멘트여야 함.

## 전제 (brainstorming 합의)

1. **A단계는 가드·검수와 거의 충돌 없이 반자동 가능**: 스캐폴딩 패턴(Task매핑 헤더·체크리스트·문서ID)을 규칙으로 감지해 `skip`/정제, 연결어는 세그먼트 안에서 추가(원문 토큰 보존 → 가드 통과).
2. **B단계는 자동으로 사실 정확성을 보장 못 함** → 사람 검수가 계약의 일부. 전 문서가 아니라 핵심 문서만.
3. **학습문서가 정본, 대본은 검수된 파생물** → 재저작 대본은 덮어쓰기 안전장치 + 별도 검수 상태 필요.

## 검토한 접근

### 범위 (D1)
- **A: 듣기용 재구성**(내용 유지) — 가드 충돌 최소·결정적이나 '가르침'은 약함. 완성도 5/10.
- **B: 적극적 재강의**(새로 가르침) — 강의력 최대지만 19문서 사람 재검수·사실오류 리스크. 완성도 9/10.
- **C: 단계적(A→선별 B)** ✅ 선택 — 전 문서 싼 안전 이득(A) 선확보 + 핵심만 심화(B). 완성도 9/10.

### 생성 방식 (D2)
- **하이브리드** ✅ 선택 — A단계=규칙/마커 결정적(AI 없음, 전 19문서), B단계=LLM(claude) 초안 + `check_token_preservation` + 사람 승인(핵심 문서만).
- 전부 LLM(B): 교일 고품질이나 명백한 버그까지 LLM·검수 비용 + 전 문서 재검수.
- 전부 결정적(C): 안전하나 재강의가 19문서 수작업 지옥 → 확장 불가.

## 권장 접근 — 단계적 하이브리드

### Stage A — 스캐폴딩 제거 + 듣기용화 (전 19문서, 결정적)
- **오디오 의도(audio intent)** 개념을 세그먼트에 부여. 두 메커니즘 병용:
  - **휴리스틱 자동 감지**: 문서 상단 Task매핑 문단, "학습 목표 체크리스트"/"✅" 헤딩 하위 체크리스트 블록, 문서ID 멘션(`(clf-tX-Y)`), 도메인·퍼센트 메타 → `skip` 또는 정제.
  - **마커 탈출구**: 학습문서(또는 script.json)에 명시 주석(예 `<!-- audio-skip -->`, `<!-- audio: 대체문 -->`)으로 휴리스틱이 못 잡는 경우 수동 지정.
- **연결 조직**: 문서 도입 1문장 + 섹션 전환구("자, 다음은…") + 마무리 1문장을 **결정적·가산**으로 삽입(원문 토큰 보존 → 가드 통과).
- 산출: 전 19문서 재합성 → gate green → reviewStatus flip. **단 [[audio-section-timestamps-shipped]]의 "음성 동일 자동 flip"은 여기 적용 불가** — Stage A는 스캐폴딩을 빼고 도입/연결문을 더해 **실제 들리는 음성이 달라진다**. 따라서 가드가 못 잡는 삽입문 오류를 막기 위해 **문서별(또는 표본) 청취 후 flip**한다.
- TDD: 스캐폴딩 감지·연결어 삽입을 순수 함수 + `--self-test`로 가드.

### Stage B — 재강의 (핵심 문서만, LLM 초안 + 사람 승인)
- 신규 서브커맨드(예 `rescript`): **섹션 단위**로 `sourceExcerpt(s)` → Claude → instructor scriptText 초안. (i) 원문 약어·수치 보존, (ii) 도입 훅·비유·예시·반복 추가, (iii) 원문 사실 범위 안.
- 산출은 **DRAFT**(reviewStatus=needs_human_review), `check_token_preservation`(사실 누락 검출) + **신규 사실정확성 검수 체크리스트**(사람이 틀린 추가 사실 검출) 통과해야 승인.
- **덮어쓰기 안전장치**: LLM 재저작이 사람 승인 대본을 조용히 덮지 않도록 별도 필드/별도 검수 상태 + 명시 재생성 가드.

## 핵심 미해결 질문 (writing-plans 전 결정)

1. **instructor scriptText 저장 위치**: 기존 `scriptText` 치환 vs 신규 필드(`instructorScript` + fallback)? B가 섹션 단위로 합치면 세그먼트별 `source↔target` 가드가 깨진다 → **세그먼트 경계 유지하며 세그먼트별 richer scriptText**로 갈지, **섹션 단위 세그먼트 + 섹션 단위 보존 검사**를 도입할지.
2. **B의 사실검수 메커니즘**: 토큰 보존만으론 불충분 — 사람 사실 정확성 패스(기존 청취 가이드/content-review 확장).
3. **"핵심 문서" 선정**: 어느 문서를 B로? (개념 토대 t1-1 등? 학습가치 높은 것?) — 사용자 결정.
4. **연결어 톤**: Stage A 연결구를 어디까지 넣을지(과하면 기계적, 적으면 효과 없음) — DESIGN.md 합니다체·절제 원칙 정렬.

## 리뷰 반영 — writing-plans 전 닫을 블로킹 결정 (적대적 리뷰 8/10, 블로킹 6)

Stage A를 writing-plans로 넘기기 전에 아래를 데이터·명세로 못박는다(미정 시 구현자가 추측하게 됨):

1. **스캐폴딩 휴리스틱은 19문서 실스캔 위에서 정의**(C1). `(clf-tX-Y)`가 본문 정당한 교차참조로 쓰인 사례 유무, 체크리스트 위치(헤딩 하위인지 본문 박힘인지 — seg004 실형태), Task매핑 문단 공통형태를 **실측**하고, 오탐 안전망(skip 후보 사람 1회 확인 또는 화이트리스트) 포함. The Assignment는 1문서뿐이라 19문서 일반화 보장 못 함.
2. **연결조직 구체 규칙**(C5): 도입/마무리/전환구의 **정확한 템플릿 문자열**, 삽입 위치(어느 헤딩 레벨), 그리고 **"삽입문은 네비게이션만 — 사실주장 금지"** 불변식(가드·검수 우회가 정당하려면 순수 안내 멘트여야 함).
3. **삽입문 평문 규칙**(C3): 위 Constraints의 기호/URL/링크 hard 규칙을 삽입 텍스트도 통과(평문만).
4. **마커 탈출구는 신규 파서 분기**(C6): 현재 `parse_segments`는 `<!--`로 시작하면 전량 skip(L199-201)이라 `<!-- audio: 대체문 -->`의 대체문을 **읽는 코드가 없다**. 마커 처리는 신규 구현.
5. **재합성 환경 사전 확인**(F1): ffprobe+ffmpeg 설치 여부(미설치 시 chapters 실측·loudnorm 불가).
6. **재승인은 변경 음성 → 청취 후 flip**(F2, 위 Stage A 정정 반영).
7. **(비블로킹·조기 부분결정 권고, S1)** instructorScript 저장 위치(미해결1)를 A 착수 전 최소 분리 결정("A=scriptText 인플레이스, B=신규필드" 등) — 안 하면 A를 B 도입 시 재작업.

## 성공 기준

- **Stage A**: 어떤 문서도 스캐폴딩을 낭독하지 않음(clf-t1-1이 "(clf-t1-1)"·Task매핑·체크리스트 문법을 더는 말하지 않음). 스캐폴딩 감지 self-test green. 19문서 재합성·gate green. **변경된 음성이므로 문서별(또는 표본) 청취 후 reviewStatus flip**(F2). '낭독→안내' 체감 확인.
